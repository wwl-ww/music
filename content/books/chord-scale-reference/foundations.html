音程、和弦与音阶基础

同一个琴键可以写成 F♯ 或 G♭。音名决定它相对于起点是几度，半音距离决定音程性质。和弦查找从根音出发，音阶查找从主音出发，两者都用相对于起点的级数表示构成音。

音程的度数、性质与音名

度数按字母音名计算，起点和终点都计入。例如 C–D 与 C–D♭ 都是二度，因为两个端点的字母仍是 C 和 D。性质按半音距离区分，C–D 是两个半音的大二度，C–D♭ 是一个半音的小二度。在十二平均律中，两个相邻的琴键相隔一个半音，两个半音合成一个全音。

C–F♯ 是增四度，C–G♭ 是减五度。它们的上方音落在同一个键，两种拼法分别表明四度和五度。升、降记号随字母音名而定，例如 G♭ 的纯五度为 D♭，大三度为 B♭。

和弦骨架与构成级数

根音是计算和弦各音位置的起点。构成级数以同根大调音阶为参照，例如以 C 为根音时，1、3、5、7 分别是 C、E、G、B。♭3 表示把同根大调的 3 降低一个半音，所以 C 的 ♭3 是 E♭，D 的 ♭3 是 F，后者由 D 大调的 F♯ 降低一个半音得到。

基本三和弦沿 1、3、5 叠两个三度，七和弦再加入一个七音。判断三和弦性质时比较相邻构成音，判断七音性质时从根音量到七音。例如 C–E–G 的两个相邻音程分别是大三度和小三度，C–B 则是大七度。

挂留和弦与六和弦

挂四用根音上方的纯四度取代三音，挂二用大二度取代三音。符号里的 7 还要求一个小七度音。例如 Csus4 由 C、F、G 构成，C7sus4 再加 B♭。在同一个 C 和弦上，F 可以下行到 E，也可以作为挂留和弦的持续音。

流行和爵士和弦符号中的 6 表示加入根音上方的大六度。C6 与 Cm6 都加 A，它们的区别在于 E 与 E♭。传统和声用语中的「六和弦」也可指三和弦第一转位，其低音为三音。

扩展音、加音与省略

从大调音阶的 2、4、6 各升高一个八度，分别得到 9、11、13。添加这些音或其升降形式，可以在原来的骨架上增加张力。以 C 为根音，♭9、9、♯9 对应 D♭、D、D♯，11、♯11 对应 F、F♯，♭13、13 对应 A♭、A。♯11 与 ♭5、♭13 与 ♯5 在十二平均律中分别等音，符号仍标示各音的作用与拼写。

几种符号可以表达同一组变化，如 C7(♭9, ♯11) 也写作 C7(♭9/♯11)。括号内的斜杠分隔变化级数，和弦符号末尾的斜杠后接音名时用于指定低音。自然延伸可简写为最高级数，如 C7 加 9 和 11 写作 C11，Cmaj7 加 9、11、13 可以写作 Cmaj13。

和弦符号说明构成与关键色彩，具体发声随配器、旋律和低音而定。十一和弦可省五音、九音，十三和弦也常省十一音。Cmaj13 可以用 C、E、B、A 演奏，保留三音、七音和十三音。明确要求省去某个音时可写 no 或 omit，如 C9(no 5) 与 C9(omit 5) 都省去 G。

斜杠和弦、转位与复合和弦

斜杠和弦写作「上方和弦/最低音」。当最低音属于上方和弦时，低音是根音、三音、五音或七音，分别对应原位、第一转位、第二转位或第三转位。Cmaj7/E 将 E 放在最下面，是 Cmaj7 的第一转位。

斜杠也可把较复杂的音组写成一个容易辨认的上方和弦加低音。F/D 把 F 大三和弦放在 D 上，实际响出 D、F、A、C，与 Dm7 构成相同。D7/A♭ 以 A♭ 为最低音，上方 D、F♯、A、C 可以在语境中理解为 A♭7(♭9, ♯11) 的配声，省去五音 E♭，上方的 F♯、A 等音对应 G♭、B𝄫。

复合和弦用横线分上下两层，每层各写一个和弦。B°C 将 C、E、G 放在下层，B、D、F 放在上层，可以表达 Cmaj11 的完整六音构成。也可叠加两组关系更远的和弦形成紧张色彩，例如 G7Emaj7(♯5)。用水平线表达两个和弦的叠置，用斜杠和音名指定单个低音。

大调、小调与自然调式

主音是音阶的中心，高八度的主音可记作 8。自然大调的相邻音程依次为全、全、半、全、全、全、半。以 C 开始可得 C、D、E、F、G、A、B、C。其他音阶的 ♭3、♯4 等级数可以相对于同主音的自然大调来理解。

和声小调1 2 ♭3 4 5 ♭6 7 8自然小调的 B♭ 升回 B，可作导音

古典旋律小调下行常回到自然小调的音列，C 旋律小调向下为 C、B♭、A♭、G、F、E♭、D、C。爵士语境常将旋律小调的上行音集用于两个方向。

关系大小调共用调号。大调的第 6 级是关系自然小调的主音，因此 C 大调与 A 小调共用七个白键音，E 大调与 C♯ 小调也互为关系调。相同的音集以不同的音作中心，句尾落点和和声重心随之改变。

五声音阶与布鲁斯音阶

大调五声从自然大调去掉 4、7。小调五声从自然小调去掉 2、♭6。两者各有五个音级。布鲁斯的常见六音音阶在五声基础上加入蓝音，小调布鲁斯加 ♭5，大调布鲁斯加 ♭3。以 C 为主音时，前者在 F 与 G 之间加 G♭，后者在 D 与 E 之间加 E♭。

布鲁斯源于美国非裔音乐传统，对爵士和流行音乐影响深远。键盘音阶将蓝音落在固定的半音位置，演唱与推弦还可以在相邻音高之间滑动，形成布鲁斯句法里的音色与语气。

宫音、主音与五声调式

C、D、E、G、A 五个音依次是宫、商、角、徵、羽。固定这组音并更换主音，得到同宫的五种调式。例如 C 宫系统的羽调式以 A 为主音，宫音仍是 C。若固定 C 作主音，C 宫与 C 羽的音列则会不同。
