主题配色

终章 延伸技巧

一段旋律已经能成立，下一步是安排它的张力、前后段落和声部。先用四组和弦手法改变局部的期待，再为一支短曲加前奏、发展部和尾奏，最后处理词句与人声和音。每种技法都要经过后一个落点检验，单个和弦、音符或词语的效果来自它所处的位置。

挂留四和弦

Csus4 由 C、F、G 构成，四度音 F 占据原来三音 E 的位置，因此和弦自身没有大三度或小三度。F 下行半音到 E 时，根音和五音都可保留，变化集中在一条线上。若 F 原来就是前一和弦的构成音，就可用同一条声部把它保留到 C 低音上，再下行解决。流行和弦符号 sus4 描述这一刻的构成音，谱面也可直接起奏它。若用在属七上，G7sus4 由 G、C、D、F 构成，C 落到 B 得到 G7，再接 C。

主和弦与属七和弦的四度挂留
挂留与解决音高走向短谱
Csus4 → CF → E
G7sus4 → G7 → CC → B，随后 B → C

如果主旋律在属和弦的位置停在 G，伴奏可以从 C 转到 G7，也可以暂时用 Csus4 并保持 C 低音。后者把张力交给 F 回到 E。终止前还有一种用法，把直接的 G7–C 拉成 G7–Csus4–C，使低音先落到主音，上方随后解决。

直接解决与挂留四度

共同的主音段之后，G7 直接解决到 C。

增三和弦与半音推进

在 C 大三和弦 C–E–G 里把五音升高半音，得到 Caug 的 C–E–G♯。把它闭合到高八度，三段都相当于四个半音。在十二平均律中，将组成音重新拼写为 E–G♯–B♯ 或 G♯–B♯–D𝄪，可得到音高类相同的 Eaug 或 G♯aug。根音的写法由声部进行与目标和弦决定。

增和弦可以在两和弦之间填一个半音。C–Caug–F 可保留旋律 C。句末用 Gaug/C 时，也可以让低音提前到 C，再由上层完成解决。

增和弦作半音桥梁

C 的五音 G 保持不变，随后上移全音到 F 和弦的 A。

减七和弦的替代与经过用法

减三和弦 Cdim 的组成音为 C–E♭–G♭。在其上继续叠小三度得到减七和弦 C°7，第四音应写作 B𝄫，在十二平均律中与 A 同音。若第四音改为 B♭，根音到七音是小七度，就得到半减七和弦 Cø7，也写作 Cm7(♭5)。四个音构成等距循环，可以重拼为别的减七和弦，但拼写会告诉读者哪一个音是根音、哪个音在向目标移动。

C–G7–C 的中间和弦可以换成 D°7/C。G7(♭9) 的音是 G–B–D–F–A♭。去掉 G，将 B 重拼为 C♭，其余四音就能写成 D°7。D°7/C 在这四音下另配 C，保留原来构成三全音的两个音，同时让低音 C 贯穿整段。

Em7 与 Dm7 的根音相距全音。在中间放 E♭°7，低音会分成两次半音下行，和弦三音也可以同向连接。

减七和弦连接两个落点

两个小节用于比较 C 到属七再回 C，以及 Em7 直接到 Dm7。

副属和弦与循环和声

副属和弦把主和弦以外的某个和弦暂时当成解决目标。C 大调的 G7–C 是主调属七至主和弦，B 上行到 C、F 下行到 E。若把 G 当局部目标，就可按同样关系写 D7–G，F♯ 上行到 G，C 下行到 B。这个局部强调仍可以继续回到 C 大调。

C 大调的常用副属七和弦
目标副属七和弦引向目标根音的音
ii · DmA7C♯ → D
iii · EmB7D♯ → E
IV · FC7E → F
V · GD7F♯ → G
vi · AmE7G♯ → A

C–Am–Dm–G7 是 I–vi–ii–V7 循环。把 Dm 改为 D7，属功能落到 G；把 Am 改为 A7，则朝 Dm 解决。两处同时改写便得到 A7–D7–G7–C 的连续属七，根音按五度关系连接。不妨保留原旋律中各版本都能容纳的音，再检查外来变音与旋律是否发生非预期的半音冲突。

同一循环中的副属和弦

原循环用 C、Am、Dm、G7，末小节返回 C。

副旋律的起音密度与音区

副旋律是一条能接续主旋律，也能同时出现的独立线。留在句间时，它能接过短暂的前景。与主旋律同时出现时，密集的主线适合配长音或慢速变化的副线，主线延长或留空时，副线才可增加起音。反向进行容易使轮廓分开，保持或斜向进行也能给乐句留空间。

Fmaj7–Em7–Dm7–F/G–Cmaj7 里，可以从各和弦选 A–G–F–F–E，前半形成连续下行，后半同音连接再落到 E。选择贴近的三音能形成副线，也让它和低音根音分工。若这条线与主旋律共享同一音区，先移动副线的八度或更换个别长音。弦乐、人声合唱类音色适合保持背景长音，仍须在转段时核对前后主次。

同一音高轮廓还要检查声部身份。例如 F–E–D–C 也能连成下行，但若它已是低音骨架，再重复在副旋律里主要会加强低音。想保留独立线条，可留用 A–G–F–E 的轮廓，再在主旋律变疏的后半段加入短经过音。

主旋律的空隙与副旋律

上声部前半较密，后半改用长音。下方只给出和声。

前奏的材料来源与首句衔接

前奏可引用主歌 A、主歌 B 或副歌的旋律和和声，也可用主体没有的专用材料。引用副歌和弦能提前建立熟悉的音响。独立前奏可在不透露主题时先建立音区和节拍，给主体的出场留位置。长度和最后的和弦都要与主体第一句连在一起判断。

以 B♭ 大调为例，低音持续 B♭，上方依次配 B♭maj7、E♭/B♭、F/B♭、E♭m/B♭。持续主音维持调性位置，上方经过大小下属的对比，让 E♭m 的 G♭ 向 F 落下，回接主歌的 B♭。简化版可只留 B♭maj7–E♭/F 两个和弦，持续主音的写法和末端低音转到属音的写法都可以接回主体。

发展部的循环换入口与暂时转调

发展部承接主歌或副歌已经确立的意象，再让材料向新处走。B♭maj7–Gm7–Cm7–F7 这一循环可以从 Cm7 起步，写成 Cm7–F7–B♭maj7–Gm7。和弦次序沿循环保持，入点移到原来的第三个和弦，听感由「已经落到 I」变成「正在朝 I 走」。器乐小曲可以保留主题的拍子与动机，让和声承担主要变化。

发展部的后半可通过 Em7♭5–A7–Dm 短暂建立 D 小调。Em7♭5 是 D 小调的 iiø7，A7 的 C♯ 向 D 解决。返回时再排布能指回 B♭ 的连接，如 C7–E♭/F–F7(♭9)–B♭。有了去程和回程，插入的新调不会把后段主题的到达感冲散。

尾奏的主题回声、重配和声与减速

尾奏可重唱副歌，也可只留下最容易辨认的一个动机，让它多出现一次并换和声。重配和弦时，根据旋律的长音、重拍与落点寻找可容纳的和弦。相同曲调放在不同低音上，仍能被认出，方向和结束的时机却可以变化。

延长记号可以在中间的 Gm7 处暂时拉开时间，再原速继续。结尾反复 B♭–E♭m/B♭，保留低音 B♭，把声音的改变集中在上方，最后渐慢回到 B♭。延长记号影响一个点，渐慢影响一段速度的变化。两者可以接续使用，位置要服从尾奏的层次。

同一个主题从进场到收束
位置材料怎样连接
前奏与主题两小节前奏保持 B♭ 低音。末端的小下属回到 B♭ 大调，主题从第 3 小节进入。
发展与主题回归第 5 小节改从 ii–V 起步，随后短暂转向 D 小调。第 10 小节回到原主题，调性和音型同时回来。
尾奏第 12 小节起保留开头动机，重新配和声。最后让低音 B♭ 留在原位，上方先换色、再渐慢归主。

同一主题的前奏、发展部与尾奏

两小节主题先以小跳上行，再逐步下行并落回 B♭。

词组划分、句位与同动机配词

给已有歌词谱曲，先把句子依语义分成词组，再找出前后半句中彼此对应的词组。可先用一字一音找出便于唱和辨认的起点，再按语气分配长音、休止和弱起。字数相同的对应词组可以共享动机。相差一个字时，可以在较短的一组前留出空位，或删掉动机内部的一次起音，保住句尾的落点。

如果较长词组只多一个轻读字，也可以让这个字在小节前的弱位进入，两个词组仍对齐同一个重拍。譬如「又起了风」比「起了风」多一个「又」，可把「又」放在前一小节末，两个版本的「起」与「风」分别落在相同位置。

前半部可让末音停在未完成的位置，譬如 F 大调停在 A，后半句再让最后一句落在 F。决定是否开放，要同时看末音和它下方的和弦。尾句如果包含短语与完整句，还可以让短语占据前一小节末端，完整句自己得到终止位置。

四行词的题头、字数差与结尾

前半部以 E 收住，保留一个可继续唱下去的落点。

主歌向副歌的推进与关键词高潮

歌词和音符逐字对好以后，还要安排语气。主歌 B 可重复同一题头，配合弱起、休止、连音或长音改变后半句。让进入副歌前的重要词停久一点，可以把这一段变成有方向的准备。休止宜放在词组边界，延音宜落在能延展的字上。

副歌的关键词多次出现时，可以保留熟悉的节奏，第一次让旋律往下走，后一次把词组末端推高，听者会同时辨认出同一个短语和新的高潮。「软」「轻」等描述词也可用短暂的空隙或稍迟的起音留出质感。若每句都在相同高点上唱，副歌的重点会被平均分掉。

进入副歌时的调性变化与关键词的高潮可以分开安排。例如 F 大调主歌以 Em7–A 收尾，已有指向 D 的属和声。D 大调副歌先从 Em7 起句再落到 Dmaj7，由和声明确新主音。同一句关键词仍可第一次下行、第二次上行，让最高音晚于副歌的入口出现。下方谱例保持在同一个调，单独比较第二次出现时的轮廓变化。

「远处灯火」的主歌准备与副歌高潮

主歌末尾延长「亮」，两次「远处灯火」使用相同的下行轮廓。

低三度、高三度与三声部和音

主旋律下方加低三度，原旋律容易保留在上方，音响更融合。上方加高三度则能扩大明亮、开阔的感觉，适合最后一次副歌或尾奏，但高音也可能更醒目。写作时可先按调内音补一遍三度，再检查重拍、长音和句尾。在 Gm7 上，旋律的 G 如果整小节配低三度 E，E 会带来十三度色彩；换成低五度 C，就能把另一条线接到 C7 的根音。两个版本的主旋律、节奏和伴奏一致。

三声部写作可从主旋律外再挑两个和弦音，给它们分别安排接近的前后音，避免每个纵向和弦都跳到新位置。长音下面可以换和弦。经过音不必一律以同一个三和弦包住，短处可让一个声部保持，或以临时的经过和弦细化连接。最后把合唱与伴奏叠起来检查，确保相邻声部与伴奏没有无意的紧张音程。

从模仿、修改到个人风格

借用熟悉作品的写法时，一次只提取一个明确的特征，比如「逐渐拉起又落下」的轮廓，或「突然撞上」的重音。把它转译成自己的节奏、速度和声部安排，再用实际演奏、录音与修改检验结果。模仿可以练习听辨和转译，比较不同作品的取舍也能帮助辨认自己反复偏好的声音。
