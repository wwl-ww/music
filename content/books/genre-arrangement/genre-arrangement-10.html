乐风 04 巴萨诺瓦

巴萨诺瓦把巴西桑巴的节奏语言和细腻的和声放在较轻的编制里。稳定的低音拍点托住短促的吉他和弦，吉他偶尔早半拍换和弦，产生向前的牵引。

七和弦、延伸音与半音收束

旋律已经落在 C 和弦的五音 G 上时，低音仍可保持 C，把上方的和弦从 C–E–G 改成 Cmaj9。B 是大七音，D 是九音。它们可放在旋律下方，和弦的宽度与色彩变了，旋律的支点仍在 G。电钢琴可以补这些较长的和声音，吉他继续弹短音。

C 大调中的和声变化
写法保留和改变的材料听感来源
C → Cmaj9低音 C 和旋律 G 保留，内声增加 B 与 D。两条延伸声部填在低音和旋律之间。
C → C/EC–E–G 仍是同一组音，最低音换成 E。低音脱离主音 C，适合在句中延续而保持流动。
Dm7/G → G7保持 G 低音，把上方 D–F–A–C 改成 B–D–F。上方的 C 先留作四音，之后半音下行到 G7 的三音 B。低音不动，属功能逐渐变清楚。
D♭maj9 → Cmaj9旋律 C 保留，低音 D♭–C 下行半音。C 从 D♭ 和弦的大七音变成主和弦的根音。F–E 和 A♭–G 也可以各走半音。

长音 C 与 D♭ 在不同音区相隔大七度或更宽，能保有张力。把相邻半音放进同一低音区，张力容易变成混浊。若保持旋律 C、改用 G7 收尾，这个 C 在 G 上是四音，可把属和弦的三音 B 错开一个音区，让 C 成为预先到来的主音。

固定旋律 C 的两种收束

旋律 C 在两小节内保持，低音从 D♭ 半音下行到 C。

贝斯拍头与和弦提前

同一和弦贯穿一小节时，贝斯常在第 1 拍给根音、第 3 拍给五音。第 2、4 拍后半的轻底鼓还可各带一个短低音。以 Cmaj9 为例，第 2 拍后的短音可以重复 C，等第 3 拍才到 G，也可以提前一次弹 G，让它在第 3 拍重新落稳。吉他提前换弦时，贝斯仍可把下一个根音留给拍头。

示范里吉他在第 1 小节第 4 拍后半已换 Fmaj9，贝斯要到第 2 小节第 1 拍才换成 F。第 2 小节结束到第 3 小节，和弦与贝斯同时在拍头换音。把两种交界交替使用，提前的起音才会产生清楚的对照。也可把提前的换弦放在进入奇数小节时。

尼龙弦吉他的拇指负责根音或五音，食指、中指和无名指拨上方的和弦音。把低音脉冲与上方拨弦写成两层，单把吉他也能支持人声。乐队里有独立贝斯时，可把较低的音交给贝斯，让吉他集中在中音区。短的和弦收音使不同起点容易分辨，避免以一整串长和弦压住节奏。

鼓组动作和配器分工

示范速度为 120 BPM。底鼓主击落在第 1、3 拍，第 2、4 拍后的轻击补纹理。小鼓可用闭式鼓边击，把鼓棒的一端贴在鼓面，以鼓棒敲鼓边，声音短而集中。它与脚踏镲分层，脚踏镲的八分反拍力度可略低。镲和鼓边击重合时局部加重即可。MIDI 力度可从反拍减约 20、叠合处加约 10 试起，实际差别随音源改变。

钢琴或电钢琴二分或全音符和弦。在主唱留白处可补短小填句。可选 Rhodes 类电钢琴。音量颤动、合唱或移相可拉开与吉他的质地，整体保持靠后。

混音先让鼓组的瞬态、贝斯低音和拨弦分别清楚，再调整高频。例如让人声与低音集中在中间、吉他略偏左、后层电钢琴略偏右。补一点人声高频可让轻声唱的字头浮出，吉他和镲仍应留出空间。保留自然的力度起伏、控制主唱的混响长度，有助于保持近距离的听感。

电钢琴的音色与调制效果
  • Rhodes 类电钢琴有清楚的起音和圆润的延音，适合放在尼龙弦吉他的短和弦之后。
  • 音量颤动让音量周期性起伏，立体声版本也可左右交替。合唱将原声与轻微变动的延迟信号叠加，使音色变厚。
  • 移相会让不同频段周期性相消，产生扫动感。三种处理都可少量使用，给鼓边和吉他的节拍留出空间。

同一旋律的巴萨诺瓦编配

原声贝斯稳住第 1、3 拍。尼龙弦吉他在第 1、3 小节末提前半拍换和弦，第 2、4 小节的低音仍在拍头换音。
