导论 音阶、音程与和弦

一段旋律在 C 大调里用了哪些音，哪些音可以支撑它，又有哪些和弦能让同一句换一种重心？音阶给出材料，音程描述相对位置，和弦为旋律提供背景。这三个概念贯穿后面的编曲示范。

C 大调音阶与音程

从 C 起依次弹白键 C、D、E、F、G、A、B，回到高八度的 C，就得到 C 大调音阶。C 是主音，其余各音依次是第 2 至第 7 级。级数可以跨调复用，例如 C 大调的第 3 级是 E，D 大调的第 3 级是 F♯。

音程度数把起点和终点都算进去。从 C 到 E 经过 C、D、E，是三度，从 E 到 G 也是三度。但琴键上 C–E 相隔四个半音，E–G 只隔三个半音，所以前者是大三度，后者是小三度。音程的度数和性质合起来才能确定距离。同一个 C 到同一个 C 是纯一度，升到下一个 C 是纯八度。

和弦结构常将根音记为 1，写作 1–3–5 表示根音、大三度、纯五度，写成 1–♭3–5 时，三音低了半音。这个 ♭ 是相对根音的间距标记。例如在 E 小三和弦中，♭3 是 G，实际谱面上的 G 可以没有降号。

三和弦、七和弦与延伸音

根音是辨认和弦构成的起点。C–E–G 以 C 为根音，改成 E–G–C 仍是同一组和弦音，但最低音成了 E，写作 C/E。辨认根音之后，才有「三音」或「七音」这些称呼。

将二、四、六度分别往上移过一个八度，得到九、十一、十三度。相对 C 来说分别是 D、F、A。符号的升降只改变所标的延伸音，例如 C7(♭9) 有 D♭。三和弦的三音能交代大小性质，七和弦的七音进一步交代类别。挂留和弦则靠四音及其后续走向形成听感。已经由旋律或其他乐器发出的音，可以在伴奏里省去。

同根音的三音、七音与九音

大三音 E 决定 C 大三和弦的性质，G 是它的五音。

调内和弦与编曲入口

C 大调的七个音都是白键。以每一级为根音，隔一个音取一个音，就能组成三和弦，再叠一个三度便得到七和弦。和弦里每个音都来自当前音阶时，它属于调内和弦。若伴奏用了 E7，它的 G♯ 就超出 C 大调音集，不过可以在下一拍走向 Am 的 A。

为旋律选和弦时，先按调内的常见和弦搭骨架，再根据旋律支点、低音方向和段落所需的色彩决定是否换和弦或增加延伸音。确定了相同的和弦，还可以改变乐器、拍点及音区。这些是同一旋律编出不同风格的几条独立路径。
