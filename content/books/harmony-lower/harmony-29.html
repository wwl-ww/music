第二十九章　转调（三）· 半音转调、中介离调

半音转调用变化半音连接两个调的和声。中介离调先用副属和弦加强共同和弦，再让共同和弦承担新调的功能。两种手法最后都要由新调的进行确立主音。

自然音转调与半音转调

用自然音转调时，前后调通过共同和弦衔接。交接前后的各声部依各自所属的音阶进行，交接处没有同名半音。以 C 大调转 G 大调为例，Am 可以从 C 大调的 vi 接作 G 大调的 ii，后续 D7 的 F♯ 已经属于 G 大调。新调有升降音并不影响此前用共同和弦完成过渡。

半音转调可以直接连接两调各自的和弦。把交接处某个音在同一声部升高或降低半音，便能引出带有新调特征的和弦。C 大调的减三和弦 B–D–F 可接到 G 大调的 D7。低音位置可改变，F 到 F♯ 的连续变化最能体现这种连接。

交接处与确认处

半音变化可以先引出一个副属和弦，短暂强调它的解决目标。随后在这个中心重述动机、形成终止，才确立新调。若后续回到原调，局部变化仍按离调解释。

上行与下行的变化半音

半音变化与新调和声
变化方向交接处新调中的作用
上行 C 大调 → G 大调。F–F♯ 升高的音常成为新调导音。F♯ 进入 D7 后上行到 G。
下行 C 大调 → d 小调。B–B♭ 降低的音常引出新调的下属方向。G 大三和弦变为 Gm 后，Gm 成为 d 小调的 iv。

同名半音相继出现在不同声部时形成对斜。G 大调转到 a 小调时，旧属和弦 D 中的 F♯ 可以在次中音，后接和弦的 F 则由中音接入。两条谱例都保留交接处的外声部 D 和 A；一个把 F♯–F 放在同一声部，另一个用对斜连接。

平行大小调中的属和弦变化

C 大调转 a 小调时，Em 的 G 升成 G♯，E 大三和弦成为 a 小调的 V，可以直接解决到 Am。在反向转调中，a 小调的属和弦 E 可把 G♯ 还原成 G。得到的 Em 接作 C 大调的 iii，再用新调的重属、属、主巩固 C。这时降低半音的作用是退出旧小调的属功能。

简洁的交接可以只占很短的时值。旋律在此后用新调重述，和声也随之维持新的主音。程序谱的短动机在 a 小调上出现，半音交接后又在 C 大调重述，并落在 C 大调的终止上。

半音转调的声部与新调终止

Am 由 C 大调的 vi 转为 G 大调的 ii，后续 D7–G 确立新调。

中介和弦前的离调

中介离调在共同和弦前加上它自己的副属和弦。副属的导音用半音引入，使原调的功能更快松动。副属常作经过性的转位和弦，例如把 A₇ 写成 A7/C♯，让低音从 C 到 C♯ 再到 D。连接到共同和弦后，仍须用接下来的进行判断它在哪一个调里承担功能。

  1. F 大调转 C 大调时，Dm 同时是 F 大调的 vi 和 C 大调的 ii。
  2. 在 Dm 前插入 A7，可以暂时突出 d 小调。以 A7/C♯ 连接时，低音 C♯ 上行到 D，七音 G 下行到 F。
  3. 到达 Dm 后，利用它在 C 大调的下属功能，接 G7–C 确立新调。

下属方向还可以继续扩展。例如 Dm 后接小下属 Fm，加入 A♭。随后 F♯ 减七和弦作为重属指向 G7，其中 F♯ 上行到 G。新增的半音变化都在趋向 C 大调终止的过程中发挥作用。

共同和弦与中介离调

Dm 兼作 F 大调的 vi 与 C 大调的 ii，接 G7–C 建立新主音。

A7–Dm 单独出现，只能说明 Dm 得到了短暂强调。它在 C 大调的终止中充当 ii 时，才成为两个调之间的中介。若之后由 B♭–C7–F 收束，整段仍以 F 为主音。
