第三十章　转调（四）· 次近关系转调

相差两个升降号的调仍有两个共同自然三和弦。中介和弦的功能随转调方向改变，决定了后面要怎样写新调的终止。

调号相差两个升降号的四个目标调

在五度圈上，从原调的调号向属侧或下属侧各走两步，得到两组次近关系调。每组含一个大调和它的平行小调。例如 C 大调和 a 小调使用同一调号，从它们出发总能得到相同的四个目标调。原调是大调时，同调式的两个目标称重属大调和重下属大调。原调是小调时，同调式的两个目标称重属小调和重下属小调。

从 C 大调或 a 小调出发的次近关系调
方向目标调自然音列的变化共同自然三和弦
重属方向D 大调、b 小调F→F♯，C→C♯Em、G
重下属方向B♭ 大调、g 小调B→B♭，E→E♭Dm、F

共同三和弦按两边的自然音列核对。重属方向的两组音列仍共有 D、E、G、A、B，从中能按三度叠置出 Em 和 G。重下属方向则共有 C、D、F、G、A，能叠出 Dm 和 F。进入新调的终止时，小调可根据声部走向引入升高的导音与旋律小调的第Ⅵ级音。

中介之后补齐新调的终止功能

先确立原调，再把共同和弦解释为新调的一部分。重属方向的中介已经有新调的下属作用，容易接属–主。重下属方向的中介已有属向，常需要在最后一次属–主之前补进新调的下属方向。

重属方向的中介与新调终止

Em 和 G 在 C 大调、a 小调里都与属功能有关。转入 D 大调或 b 小调后，它们都可进入新调的下属方向。这样，中介和弦本身就能开启下属–属–主的路线。

Em 与 G 的音级转换
中介C 大调a 小调D 大调b 小调
Emiiiviiiv
GVVIIIVVI

从 C 转往 D 时，G 可由 V 改作 IV，接新属七 A₇。A₇ 中的 C♯ 指向 D。也可让 Em 由 iii 改作 ii，再用新调的阻碍终止延长展开。从 a 转往 b 时，Em 可改作 iv，接含 A♯ 的 F♯₇ 归到 B。在较长的乐句里，可在新调加入重属或短暂离调，再以终止确立新主音。

a → b 的展开谱例先以 F♯₇/C♯ 进入 Bm/D，随后把低音 D 升成 D♯，将 Bm/D 改为 B₇/D♯，短暂引向 b 小调的 iv。低音 C♯–D–D♯–E 贯穿这段进行，最后的 F♯₇–Bm 巩固 b 小调。

目标是重属调的平行调时，可以把中介直接接入目标调，也可先在同调式的重属调终止，再作一次平行关系转调。例如 C 直接到 b，或先经过 D。谱例标出中介的双重级数，后续按新调解读。短谱沿用原调调号，变化音显示在相应音符旁。

重属方向的中介与新调终止

重下属方向的下属功能补强

Dm 和 F 在原调里属于下属方向。它们转入 B♭ 大调或 g 小调后都具有属向作用。譬如 C 大调的 IV，也就是 F 大三和弦，转作 B♭ 大调的 V 后便可直接归主。这种写法能完成收束，新调的功能经过较短。

Dm 与 F 的音级转换
中介C 大调a 小调B♭ 大调g 小调
Dmiiiviiiv
FIVVIVVII

需要让新调在终止前有更完整的展开时，可让新属七先阻碍解决，再引入新调的下属和弦。例如 B♭ 大调的 F₇–Gm 是 V₇–vi。Gm 后接 E♭，再写 F₇–B♭，便形成 IV–V₇–I。此时 E♭ 也从属七内部的七音扩展为下属和弦的根音。

C 或 a 转到 g 小调时，两个共同和弦 Dm 与 F 都含 g 自然小调的第Ⅶ级 F。让 F 向下到第Ⅵ级 E♭，便能引出新调的下属方向。也可以让同一声部先用旋律小调的下降线，再用上升线引向终止。谱例把这一过程写在低音里 。

重下属方向的终止补强

次近关系转调的段落用途

次近关系调较少作为开头乐段的结束调性，常在展开部分作为经过调性。旋律动机保持节奏与音程轮廓，再随和声移到新高度时，模进能维持发展的连续性。谱例中，C 大调的高声部以带八分音符的短动机组织 IV–V₇–I，D 大调在高大二度处复用同样的节奏和和声骨架。G 和弦在两段交接处由 C 大调的 V 转作 D 大调的 IV。

逐步转调的每一站

逐步转调把多次近关系转调连起来。每一步只跨一个升降号，通过一个中介调也能到达次近关系调。例如 C 到 D 可以经 G 大调，也可以经 G 的平行小调 e。中间一站应能听到自己的主音与属向支持，例如 D₇–G 或 B₇–Em。

同一调号距离的不同路线
路线各步调性调号变化
两步，属侧C → G → D，或 C → e → D逐步增加升号
四步，下属侧C → F → B♭ → E♭ → A♭逐步增加降号
四步，经小调C → d → g → c → A♭调号同样逐步增加降号
四步，大小调混合C → d → B♭ → c → A♭以各站的终止确立当时的大小调
同型展开e → b → f♯ → c♯每一站增加一个升号

每一站都与下一站保有较多共同音。向降号侧走四步时，第一站可选 F 或 d，第二站可选 B♭ 或 g，第三站可选 E♭ 或 c。每站用自己的属到主确立调性，再选下一站。较长的路线也可反复使用一组功能，例如让前一小调的 III 改作后一小调的 VI，接新属七再归主。
