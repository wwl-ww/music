第三十二章　和声音型、持续音

同一组和弦可以写成整齐的四部连接，也可以改变发音的次序、节奏和音区。持续音则让一个音跨过几次和弦更换，在变化中维持同一个功能支点。

从和声骨架到音型

和声音型把一个和弦的发音组织成可辨认、可重复的样子。先写出和弦更换的位置、低音和主要声部，再决定哪些音同时发声，哪些音先后进入。同一个音型可以跨过多个和弦，因此要分清发音次数和换和弦次数。

和声音型的组织方式
写法发音怎样组织主要听感
节奏音型选取同一和弦中的一个音、几个音或整个和弦，按一定节奏反复发音。重音、切分或弱位反复带来节奏动力。
华彩音型把同一个和弦的各音先后奏出，形成上行、下行、回转或交替的分解和弦。慢速多呈飘动的背景，快速更有华彩和动力。
混合音型把重复发音与分解进行放在同一音型里。较快时节奏感往往更突出，较慢时更容易辨认分解轮廓。

节奏音型的声部、音区与乐器

低音可以拉长，上方和弦在弱位重复；也可以先让上方在强位发音，再让低音在下一拍进入。只反复一个和弦音，或用两个音组成节奏型，也能在其他声部的支撑下维持原来的和弦音响。

三拍子的舞曲伴奏常用一拍低音加两拍上方和弦。重音首先由低音和拍位体现，后两拍可以维持同一和弦。低音与上层和弦的先后发音并不增加和弦更换的次数。

音型化后仍需核对换和弦处的声部连接与不协和音解决。低音区的重复较厚，高音区的重复较轻捷。为钢琴写同时发音的和弦时，上方常用密集排列，以便演奏并保持清晰的节奏。乐器、音区和段落的表现需要会共同影响音型选择。

华彩音型的分解与收束

华彩音型也叫分解和弦或琶音。分解可以在上方，下面保持低音；也可以在低音，上方保持和弦。两手交替时，可把同一个和弦的音分到不同音区，形成较宽的活动范围。分解既能作为伴奏背景，也能承担独奏技巧或场景描绘。

把和弦拆开仍要保留可以追踪的和声骨干。留音、倚音或七音的解决可以藏在音型里，换和弦时仍由承担该音的声部完成。例如上方 C 从 IV 末尾延续到 V₇，即使低音已换成 G，仍在第二拍下行到 B。写作时兼顾织体的流畅性与乐器的手感。音型选定后通常保持一段时间，再随乐句或段落改变。短曲也可在结束前稍作停顿或变化，随后回到原音型收束。

混合音型与和弦外音

在一个单位中先同时奏响几个和弦音，再把和弦分开演奏，可以让重音和流动感并存。分解音型中还可加入经过音、辅助音，偶尔在强位用倚音。外音要有可辨认的来去，承接处的和弦并不随每一个加工后的音更换。

程序谱固定 C 大调的 I–IV–V₇–I，每个和弦占一小节。三拍舞曲用三拍子，其余写法用四拍子。速度可独立切换，用于比较同一混合写法在慢速和快速中的重心。

持续音的起止与不协和

持续音也叫长音，常布置在低声部。它跨过几次和弦更换，上方的和声可以变化、暂时离调，甚至出现不含这个音的和弦。分析时先辨认持续音上方的和弦与连接，再判断持续音所维持的大方向。延音跨越小节线时，同一音高只在开头起音 。

起止看和弦音，中间看整体功能

传统写法通常让持续音在开始和结束时都是和弦音。持续音在中间可以暂时形成不协和而保持同一音高，由上方和声变化解除张力。标记 T 或 D 加长横线，分别表示延长的主功能或属功能。

例如低音 C 在 G₇ 和弦下保持时，B 与 C 形成不协和。上方的 B、F 仍可分别趋向 C、E，低音 C 随后重新成为主和弦音。转位的判断也要参照上方和声及它的独立低音。固定在最下方的持续音可以作为另一层来标记。

延音线本身只说明同音继续发声。留音的张力集中在某一次换和弦及其局部的级进解决。持续音通常跨过几次和弦变化，即使短暂出现不协和，也可以等上方和声回到与它相容的位置。

主、属、双持续音与段落功能

按持续音的音级和功能分类
类型开始与结束常见段落作用
主持续音主音从主和弦开始，通常在主和弦上结束。常在开头、呈示或终止处强调主调，适合小范围离调，较常走向下属方向。
属持续音属音可从终止四六或各种属和弦开始，在属和弦上结束，再进入主和弦。可用于中段展开、再现前准备，或延长终止中的属功能。上方容许较远的离调或转调。
双持续音主音和属音同时延长，通常主音在下形成纯五度。整体多由主功能主导，也能作为模仿风笛或芦笙的背景音响。
其他音级小调第Ⅲ级是平行大调的主音，也可用作持续音。大调的Ⅳ级、降Ⅶ级等也可短暂保持。多用于局部色彩、风格或背景，结构上的作用通常较小。

主持续常稳定现有的中心，属持续则能把一段离调和转调仍约束在归主的期待中。再现前尤其常用属持续积累张力，等到主音与主和弦回归时，低音的功能也随之改变。

主、属、双持续的基本范例共用 I–IV–V₇–I 的上方材料。离调的两例分别在主持续音上短暂强调下属、在属持续音上短暂强调重属。终止四六写法和小调第Ⅲ级持续音另以短句说明。

和声骨架上的持续音功能

独立持续音与四部中的持续低音

持续音可以占用原四部中的低音，和弦在上方三个声部内展开。也可以额外加一个低声部，此时原来的四部和声仍照常进行。放在中声部或高声部时，持续音往往更像背景，其他声部继续承担低音与和声方向。

持续音的重奏、交替与加饰

持续音可以按一定节奏重奏，双持续音也可通过主音、属音交替发声来维持。在一个持续音旁加入短暂的倚音，再回到它所固定的音高，可以增加动力。辨认时要看哪个音贯穿和弦变化，哪些短音只改变发音方式。
