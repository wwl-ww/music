第三十六章　同主音综合调式（二）· 和声大调

和声大调在自然大调的基础上降低第Ⅵ级。主和弦保持大三和弦，降Ⅵ改变了小下属和上主和弦的结构与声部走向。

降Ⅵ级与下属和弦的结构

C 和声大调的音列是 C–D–E–F–G–A♭–B–C。Ⅵ级降低后，旋律中 A♭–G 是下行半音；A♭ 到导音 B 则是增二度。大主和弦保留 E，大属和弦保留 B。iv 与 iiø₇ 却和同主音和声小调的同级和弦相同。分析时要结合主和弦的三音和整句的收束来判断调式。

C 和声大调常用的下属和弦

以 A♭ 为根音叠出的 A♭–C–E 是 ♭VI 增三和弦，少用。借用同主音小调的 A♭–C–E♭ 大三和弦时，还改变了第Ⅲ级，属于另一种综合调式用法。

自然大调与和声大调的对应结构

替代、对置与半音连接

替代用法把自然大调中的某个和弦换成和声大调的同级和弦，例如在原来 IV 的位置使用 iv。对置用法把变音后的和弦放在自然同级和弦之后，例如 IV₆–iv₆。在对置中，A 和 A♭ 应由同一声部下行半音连接。

降Ⅵ级的两个检查点

  • 本位Ⅵ级与降Ⅵ级分给不同声部会形成对斜。对置时把两音安排在同一声部。
  • 接属组和弦时，避免同一声部从 A♭ 上行到 B 的增二度。可让 A♭ 下行到 G，另一个声部承担导音。

降Ⅵ与导音在同一和弦里同时出现时，须按纵向结构分析。上面的限制针对同一条旋律声部的跳进。例如在 G–B–F–A♭ 中，B 和 A♭ 可以分别向 C、G 解决。

辅助小下属四六依附于主功能，低音仍是主音 C；终止四六依附于属功能，低音是属音 G。采用 iv₆ 接终止四六时，降Ⅵ级在低音，可以直接做 A♭–G 的下行半音，同时把 C 保留在上方。补充变格终止也可以回到音区更高的主和弦，改变最后的音响层次。

键盘谱上的声部可以跨谱表记写。例如 B♭ 和声大调中的 G♭–F 可从高音谱表写到低音谱表。两音仍是同一内声部的降Ⅵ–Ⅴ级下行半音。

小下属的终止与辅助用法

降五音的上主六、七与五六

ii°₆ 以三音 F 为低音，通常重复这个三音，突出下属功能。它可由 I、I₆ 或下属方向的和弦引入，用后可回到 I、I₆，也可接终止四六或属组。iv 与 ii°₆ 连接时，可以保持低音 F 和上方的 A♭，让 C 上行到 D。与自然大调的 ii₆ 对置时，五音 A 与 A♭ 保持在同一声部。

iiø₇ 与 iiø₆₅ 通常保留 D、F、A♭、C 四个音，用途与 ii°₆ 相近。半减七结构需要完整显示五音与七音。C 可以在进入终止四六时保持，再于属和弦下行到 B。上主七与上主五六也可各自作自然、变音两种同级结构的对置。

它们还可用在乐句内部。不改变主音时，可让低音级进下行、高音逆向上行，共同音保持，变音和弦便作为同一和声走向中的经过色彩。
