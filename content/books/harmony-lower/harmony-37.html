第三十七章　那波里六和弦

在降Ⅱ级上构成大三和弦，再把三音放入低音，就得到那波里六和弦。它常在终止前承担下属功能，降Ⅱ级可以直接或经过主音走向导音。

构成、低音与下属功能

那波里和弦的根音是降上主音（♭Ⅱ级），构成音是 ♭Ⅱ、Ⅳ、♭Ⅵ。在 C 大调和 c 小调中，这三个音都是 D♭–F–A♭。第一转位以三音 F 为低音，称那波里六和弦，记作 ♭II6 或 N6。它的降Ⅱ级来自同主音弗里几亚调式。这个和弦最初以第一转位常见于小调，随后也进入大调。

从小下属和弦 iv 看，F–A♭–C 中的 F 和 A♭ 均保留，F 上方的纯五度 C 换成小六度 D♭，听感仍有下属方向。 四部写作通常重复低音 F，也就是和弦的三音。

那波里六和弦的引入

以 C 为主音的三种引入方式
前面的和弦连接要点
主和弦 I 或 iC 可上行半音到 D♭。C 大调的 E 可上行到 F，避免 E 直接下行到 D♭ 的增二度。
IV、iv、大调 ii6 或小调 ii°6保留共同音。IV 的 A 降为 A♭，ii6 或 ii°6 的 D 降为 D♭。同名半音放在同一声部，避免对斜。
♭II 的副属和弦A♭ 或 A♭7 指向 D♭。安排 C–D♭ 与 G♭–F 的半音解决，其余声部平稳连接。

对斜出现在一个音与它的半音变化先后分属不同声部时。例如四部谱里，IV 的 A 若出现在高音，进入 ♭II6 时 A♭ 也放在高音，便能听见同一条声部线上的半音变化。ii°6 与 ♭II6 已共用 F 和 A♭，只需要把 D 降成 D♭。

接属功能组与复式终止

♭II6 后面常接 V 或 V7。以 C 为主音，D♭ 可以直接下行到导音 B，这个音程是减三度。若 V 含 D，前后的 D♭ 与 D 可以分处不同声部。也可在 D♭ 与 B 之间加入 C，把减三度分成两个下行半音。

常用写法中，♭II6 直连原位 V7时，省去 V7 的五音 D，给 D♭→B、A♭→G 和 F 的连接留出位置。若属七用转位，可以保留四个和弦音。例如 V42 以 F 为低音，低音从那波里六和弦保持到属七，随后下行到 E，形成 I6。

那波里六和弦到终止四六的声部排列

把根音 D♭ 排在五音 A♭ 的上方，让 D♭→C 与 A♭→G 形成平行四度。若 D♭ 在下、A♭ 在上，这两条声部会形成 D♭–A♭ 到 C–G 的平行五度。

也可以把重属和弦插在 ♭II6 与属和弦之间。选择重属的转位或重属导七时，低音可以走 F–F♯–G。重属后既可直接到 V，也可先经过属低音上的终止四六，再到 V 或 V7。

那波里和弦进入属功能组

直接接原位 V₇。D♭ 到 B 是减三度，V₇ 保留三音 B 和七音 F，省去五音 D。

变格终止与下属之间的辅助和弦

♭II6 可以直接接 I 或 i，构成变格进行。它可用来结束句子，也可在已经完成的终止之后接回主和弦，作为补充终止。以 C 大调为例，F–A♭–D♭ 的上方声部可以分别下行半音到 E–G–C。

在 IV–♭II6–IV 这样的进行里，♭II6 是两个下属和弦之间的辅助和弦。把 D♭ 放在旋律最上方，C–D♭–C 的辅助线条更清楚。

那波里和弦的变格、辅助与短暂主化

♭II₆ 直接回 I。三个上方声部均下行半音，低音 F 下行纯四度到 C。

原位那波里和弦

原位写法的低音是降Ⅱ级，记作 ♭II。由于第一转位是最早常见的形式，原位在传统写作中反倒是较特殊的用法。它往往由下属功能组引入，也可由自己的副属和弦引入，在终止之前暂时突出 ♭II 的地位。

原位 ♭II 接 V7 或 V9 时，低音从降Ⅱ级到属音，可上行增四度，也可下行减五度。以 C 为主音，D♭ 上行到 G 与下行到 G 都跨六个半音，写法和声部方向不同。原位 ♭II 的延长可支撑较长的织体，随后回到 V–I 或 V–i，仍可作为同一调内的扩充终止。
