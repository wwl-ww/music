第四十一章　加速转调（二）· 降Ⅵ、那波里与主和弦变化

降Ⅵ级和弦、那波里和弦以及改变三音的主和弦，都能把相距较远的调连起来。中介和弦在两调中各有一个功能，后面的进行使新功能成立。

降Ⅵ级和弦作为中介

C 大调借用的 ♭VI 是 A♭–C–E♭。从 A♭ 的根音往上、下推纯五度，可以得到三种读法。A♭ 是 E♭ 大调的 IV、A♭ 大调的 I，也是 D♭ 大调的 V。方向反过来时，保留 C 大调原有的 IV、I 或 V，把它重新理解为后调的 ♭VI。

以 C 大调为起点的降Ⅵ级中介路线
原调 → 后调的功能中介和弦后调与调号差
♭VI → IVA♭ 大三和弦E♭ 大调，降号方向 3
♭VI → IA♭ 大三和弦A♭ 大调，降号方向 4
♭VI → VA♭ 大三和弦D♭ 大调，降号方向 5
IV → ♭VIF 大三和弦A 大调，升号方向 3
I → ♭VIC 大三和弦E 大调，升号方向 4
V → ♭VIG 大三和弦B 大调，升号方向 5

用原调 ♭VI 时，可以从 I 直接进入，或借 V7–♭VI 的阻碍进行引入，也可用 ♭VI 的副属和弦。例如 C 大调内可先用 E♭7 指向 A♭，再把 A♭ 作为新调的和弦继续。旋律若能保留中介的共同音，如 C 到 A♭ 两个和弦共用 C，转折可以和原来的旋律自然衔接。

用后调 ♭VI 时，原调的自然和弦先按本调功能出现。例如 E 大调的第Ⅵ级 C♯ 降为 C，第Ⅲ级 G♯ 降为 G，和主音 E 组成 C 大三和弦。C–E–G 在原调是 I，后接 B7–E 后，它又成了 E 大调的 ♭VI。

那波里和弦作为中介

原调的大、小调式都能借用降Ⅱ级大三和弦。以 C 为主音，即使原调是 c 小调，中介仍是 D♭–F–A♭。♭II 与 ♭II6 的构成音相同，选择转位可以保留原低音的走向，例如 C 的 ♭II6 可以直接成为 D♭ 大调的 I6。

以 C 为原调主音的那波里中介路线
原调 → 后调的功能中介和弦后调与大调调号差
♭II → IVD♭ 大三和弦A♭ 大调，降号方向 4
♭II → ID♭ 大三和弦D♭ 大调，降号方向 5
♭II → VD♭ 大三和弦G♭ 大调，降号方向 6
IV → ♭IIF 大三和弦E 大调或 e 小调，升号方向 4
I → ♭IIC 大三和弦B 大调或 b 小调，升号方向 5
V → ♭IIG 大三和弦F♯ 大调或 f♯ 小调，升号方向 6

表中调号差按主音所在的大调比较。后调落到小调时，用该小调本身的调号。反向的 IV、I、V 须具有大三和弦的结构，才可保持原音响并作为后调的 ♭II。若原调为小调，就要相应选择可用的大三和弦形式。

用后调 ♭II 时，可沿用那波里六和弦的下属功能，让它接新调的终止四六或属七。改用等音调时也可以改写拼法。例如 B♭ 调的那波里和弦是 C♭–E♭–G♭，若把它交给后调作 I，可按 B 大调写成 B–D♯–F♯。实际按键相同，音名与新调功能一致。

改变主和弦的三音

大调把 I 的三音降低半音，得到同主音小主和弦。例如 C–E–G 变成 C–E♭–G 。 小主和弦通常由原调 V7 引出。若转调发生在乐句或段落交界，也可用大小主和弦直接对置。小调则可把 i 的三音升高半音，以原调属功能引出大主和弦，再把它当作目标调的自然和弦。

改变主和弦三音后的十二个目标
原调、中介与调号差后调为大调后调为小调
C 大调 → Cm，降号方向 2B♭ 大调的 iig 小调的 iv
C 大调 → Cm，降号方向 3E♭ 大调的 vic 小调的 i
C 大调 → Cm，降号方向 4A♭ 大调的 iiif 小调的 v
a 小调 → A，升号方向 2D 大调的 Vb 小调的 VII
a 小调 → A，升号方向 3A 大调的 If♯ 小调的 III
a 小调 → A，升号方向 4E 大调的 IVc♯ 小调的 VI

同一个小主和弦可在不同调中成为小属、下属或主功能一侧的和弦。若由 C 大调经过 Cm 转到 E♭ 大调，Cm 保留的 C 和 G 为调式转换提供联系。新调的 A♭–B♭7–E♭ 随后把听感重心从 C 移到 E♭。

中介和弦与后调的确认

同主音综合调式的转调路线

C 调的 G7 阻碍解决到 ♭VI。后面的 D♭–E♭7–A♭ 又让同一个 A♭ 和弦成为新主和弦。

同一对调常有几条路线。若中介成为新调的下属功能，容易接成完整的下属–属–主。改变主和弦大小性质也能让不同环节的调式色彩形成对比。两点可以同时满足，例如借来的小主和弦直接成为后调的小下属。

近关系调同样可以采用这种手法。例如 C 到 G 本有自然共同和弦，也可先用 E♭7 引到 A♭，再把 A♭ 当作 G 的那波里和弦，经终止四六、D7 回到 G。延长的中介是为了改变和声色彩。

两种中介解释组合使用的例子
转调中介和弦功能换算
C 大调 → g 小调A♭ 大三和弦原调 ♭VI → 后调 ♭II
a 小调 → D 大调B♭ 大三和弦原调 ♭II → 后调 ♭VI
C 大调 → F♯ 大调G 大三和弦原调 V → 后调 ♭II
E 大调 → B 大调C 大三和弦第一转位原调 ♭VI6 → 后调 ♭II6

E 大调到 B 大调的例子结合了两种借用。G7 先把 C 引作 E 的降Ⅵ级。C/E 的低音 E 同时是 B 调的第Ⅳ级，正适合作那波里六和弦的低音。随后 E→F♯ 把低音导向 B 调的属音，和声经终止四六与 F♯7 到达 B。
