第四十二章　等和弦转调（一）· 减七等和弦转调

一个减七和弦可以保留原来的四个音高，重新指定根音、改写音名，再走向新的主、属或下属和弦。选择哪一种读法，取决于目标调与中介和弦的解决方式。

等音改写与解决倾向

十二平均律中，G♯ 和 A♭ 可以是同一个实际音高。写作 G♯ 时，它可以向上解决到 A。写作 A♭ 时，它也可以向下解决到 G。和弦中的一个或几个声部作等音改写，整体实响可以保持，和弦的结构、根音或功能却能改变。这类实际音高相同、记谱和解释不同的和弦称为等和弦。

同一琴键的两种写法和解决方向 表明后续解决怎样区别两种解释。等和弦转调可使用减七、属七与增三在等音改写后的不同性质。本章从减七开始。

等和弦转调常可在同一和弦上完成重新解释，转折较集中。段落交界可以让新调与新段同时开始。也可先放缓速度、减弱力度，或让旋律简化，使和声的重新解释更清楚。

四种记法与三种实际音响

全减七和弦从根音起连续叠置三个小三度，根音与七音构成减七度。回到高八度根音还差三个半音，写出来是增二度。十二平均律中，增二度与小三度同为三个半音，所以这四个位置把八度均分成四份。任一位置都可改写成根音，其余各音随之重新拼成三度叠置。

同一组实际音高的四种全减七拼写
根音按根、三、五、七排列根音向上解决到
BB–D–F–A♭C
G♯G♯–B–D–FA
E♯E♯–G♯–B–DF♯
DD–F–A♭–C♭E♭

例如把上方的 A♭ 改写为 G♯ ， 根音就从 B 改为 G♯。最低音仍是 B，记谱上变成 G♯ 减七的第一转位。把根音每次升半音，在一八度的十二个位置上都能建全减七，实际只得到以下三组音高集合。根音升三个半音就会回到同一组。

  • C–E♭–G♭–B𝄫，其中 B𝄫 与 A 等音。
  • C♯–E–G–B♭。
  • D–F–A♭–C♭，其中 C♭ 与 B 等音。

这一对称性适用于全减七。半减七的七音比全减七高一个半音，三个连续小三度的条件随之消失。C 大调若写 B–D–F–A，所得是半减七；降低 A 得到 A♭，才是本章使用的导音全减七。c 和声小调本来就有 A♭。

三种中介角色与二十四个调

先判断减七和弦指向的和弦，再判断那个和弦属于后调的哪一组。以 C 为主音，指向 C 的导音减七 B–D–F–A♭ 记为 T 路线。指向 G 的重属减七 F♯–A–C–E♭ 记为 D 路线。指向 F 的下属副属减七 E–G–B♭–D♭ 记为 S 路线。T、D、S 在这里表示减七随后指向的功能。

例如先解决到 A。若 A 是主音，后调为 A 或 a。若 A 是后调的属音，按五度关系得主音 D。若 A 是后调的下属音，得主音 E。每种角色产生四对同主音大小调。同一个减七实响覆盖十二个主音和各自的大小调式，实际选择取决于原调怎样引入以及后调怎样建立。

按新、旧主音的距离判断功能换算

将目标主音写在原主音上方的一八度内，按十二平均律数出上行半音数。若原、新主音同高，按 0 计算。三类距离对应三种固定的功能换算。

目标主音上行距离与减七中介的新功能
上行半音数代表音程功能换算
0、3、6、9同度、小三度、三全音、大六度T、D、S 各保持原角色
2、5、8、11大二度、纯四度、小六度、大七度T → D、D → S、S → T
1、4、7、10小二度、大三度、纯五度、小七度T → S、S → D、D → T

四种根音位置每隔三个半音，所以新主音升三个半音时，同一个减七仍能承担同一角色。其余两类可从先解决到 A 的例子推得。把 A 当主，主音是 A；把它当属，主音是上方纯四度的 D；把它当下属，主音是上方纯五度的 E。两种功能转换的主音距离分别是五个和七个半音，加减三的倍数就得到对应各行。

由 C 到 D 上行两个半音，原调的导音减七转成新调的重属减七。由 C 到 E 上行四个半音，同一组音转成下属副属减七。选用同一个中介时，应把后续和弦配成相应的功能路线。

一个减七实响的三种新调功能

旧拼法的 A♭ 改写为 G♯。作为 a 小调的导音减七，四个声部级进解决到小主和弦；随后再以小调终止加以确认。

中介减七的引入与记谱

可从原调的主和弦、属和弦或下属和弦等不同位置引入。引出时优先保留共同音，把变化音放进同一个声部的级进线条。C 大调的 V 与 B–D–F–A♭ 可共用 B、D，IV 可保留 F。若从无共同音的 I 进入，则可用 C–B、E–F 和 G–A♭ 的半音连接。

中介减七在谱面上的三种写法
写法C → a 的例子
按原调写写 B–D–F–A♭，后面的 a 小调进行显示新功能。
按后调写在和弦初次出现时就写 G♯–B–D–F，便于读出向 A 的解决。
按两调分别写在延长或重复中改写 A♭ 为 G♯。若同一音持续，用延音线连接实际音高相同的音。

持续的等音可跨小节写成降 A 连到升 G 。 左边保留原调的拼写，右边显示新调的导音身份。延音线把两段时值并成一次起音，下一次起音才进入解决音 A。

常规、倚音与转化解决

常规解决

以导音减七到主和弦为模式，每个声部都作级进。例如在 C 调，B 可上行到 C，A♭ 下行到 G，D 和 F 可分别下行到 C 和 E。由重属减七或下属副属减七实现转调时，仍在局部按导音减七解决，但接到的是后调的 V 或 IV，再按这一功能继续。从同一减七实响出发的三条谱例演示了这种处理。

倚音解决

保留一个共同音作为目标和弦的根音，其余声部级进到目标和弦。在 C 调，以升Ⅱ级 D♯ 为根音的减七是 D♯–F♯–A–C，共同音 C 可以保持后接 I。以升Ⅵ级 A♯ 为根音的减七是 A♯–C♯–E–G，共同音 G 保持后，A♯、C♯、E 都上行半音，形成属七。

同功能内的转化解决

先将减七中的一个音降低半音，可转化为同一功能组内的属七或增六和弦，随后完成解决。这里的“三音”“七音”根据减七在后调中的根音来数。

倚音与同功能内的转化解决

C 保持为主和弦根音。这一处的减七根音是升Ⅱ级 D♯，其余声部从 A、D♯、F♯ 级进到 G、E、G。

重属组中的增六通常接终止四六，也可按声部条件接 V7。采用终止四六时，先让 A♭ 下行、F♯ 上行半音到相隔八度的两个 G，再处理属低音上方的四度和六度。后面的属七将调性导向 c 小主和弦。
