第四十三章　等和弦转调（二）· 属七等和弦转调

属七和弦的小七度可以等音重写成增六度。和弦的实际音高保持不变，原来的属功能可以变为新调的增六和弦，反方向也成立。

大三小七结构与增六度

狭义的属七和弦是建在调式属音上的 V7。广义的属七结构指任何根音上的大三小七和弦，即大三和弦加一个根音上方的小七度。副属七也有这种结构。小七度与增六度都是十个半音，因此同一组音既可按属七功能解释，也可按增六和弦解释。

以 G 为低音，G 到 F 是小七度 。 把 F 改写为 E♯ 后得到增六度 。

G–B–D–F 的三种和弦读法
调内功能记谱有方向的声部
C 大调 V7G–B–D–FB 倾向上行到 C，七音 F 下行到 E。
B 调德国增六和弦G–B–D–E♯外声部 G 下行、E♯ 上行，向两端的 F♯ 解决。
B 大调倍增三四和弦G–B–C𝄪–E♯增六度仍向外解决，C𝄪 倾向上行到 D♯。

德国增六和弦也叫增五六和弦。倍增三四和弦将其中的 D 等音写成 C𝄪，它与低音 G 形成倍增四度。改用 C𝄪 的拼写，可以让中声部上行到大调主和弦的三音 D♯，同时外声部继续指向属音 F♯。

向下或向上半音转调

属七等换为增六时，新调主音比原调主音低半音。例如 C 大调 V7 的根音 G，正好是 B 调的 ♭Ⅵ。原调通常选原位属七，并把七音放在高声部。这样改写后，♭Ⅵ 与升Ⅳ构成的增六度位于外声部，可以向外解决到新调属音的八度。

新调的德国增六和弦可经终止四六和弦到 V7，也可以直接到 V7。后一种写法可省掉 V7 的五音，让外声部同时到属音。直接连到含五音的 V 或 V7 时，若 G–D 同向下行到 F♯–C♯，就会形成平行纯五度。这个特定增六解决语境中的写法叫莫扎特平行五度，可作为传统声部进行的局部例外。

增六等换为新调的本属七时，新调主音比原调主音高半音。例如 B 大调的德国增六和弦以 G 为低音，将 E♯ 写成 F，就成为 C 大调的 G7。改写后，B 是新调的导音，F 是属七的七音，分别上行到 C、下行到 E。等音前后的低音也可以用转位来安排。例如 B♭ 大调的 G♭–B♭–D♭–E 用 B♭ 作低音时，可写成 F♯7/A♯，即 B 大调的 V₆₅。

半音转调与增六和弦的解决

G7 的七音 F 改写为 E♯。新调通过属音低音和终止确立。

以副属七扩大转调范围

任一个大三小七结构的副属七，只要它的临时主音比目标调的主音高半音，都可以改写为目标调的德国增六和弦。反推时，可从目标调主音向上半音找到临时主音，再往上纯五度找到作为中介的副属七根音。前半段平稳引入副属七，重写后用新调的终止确立实际归属。

副属七转作新调的德国增六

D♯7 本可到 G♯，改写后却向 G 大调的属音 D 展开。
从减七经过副属七

若已出现减七和弦，可把它的根音降低半音，保留其他三个音，得到属七结构。例如 A♭ 大调里 A–C–E♭–G♭ 改为 A♭–C–E♭–G♭，就成了 A♭7。再把 G♭ 重写为 F♯，得到 C 调的德国增六和弦，可经终止四六到达 C 主和弦。第一步实际改变了 A 的音高，第二步只改变 G♭ 的拼写。

反过来，原调的增六和弦也可等换为后调的副属七。B 调的 G–B–D–E♯ 写成 G7 时，在 C 大调可作 V7，在 F 大调也可作 V7/V。走后一条路线时，G7 先到 C，继续用 C7–F 建立 F 大调。第一次解决的 C 是中间目标。

附加增六度那波里和弦与大下属

也可以以新调的 ♭Ⅱ 或 Ⅳ 为低音，在原有的大三和弦上另加一个增六度音。这两种四音结构都与属七等音，区别在于外声部的增六度向哪个音收束。

大下属路线也可插入新调的 V₄₂，再到 I₆。以 C 大调为例，F–A–C–D♯ 改接 G7/F。低音 F 保持，C→B 与 D♯→D 各降半音，A→G 降全音。随后属七的七音 F 下行到 E，把第一转位的主和弦引入。两种路线都可用补充终止巩固新调。

附加增六度和弦的两种主和弦解决

D♭7 的七音 C♭ 改写为 B，外声部向 C 收束。
