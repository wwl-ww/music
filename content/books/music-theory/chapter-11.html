第十一章　调式变音与半音阶

调式变音的名称取决于它改变了哪个音级，在旋律中的作用则取决于它怎样连接前后的音。半音阶用这些变音填补自然音阶里的全音间隔。

调式变音及其记谱

变音与调式变音的参照

变音是相对于七个基本音级而言的。调式变音是相对于当前调式的音阶而言的。

第三章把基本音级 C、D、E、F、G、A、B 升高或降低后得到的音称为变音。例如 F♯ 相对于基本音级 F 高半音，因此是变音。本章要判断的是这个音有没有改变当前调式原有的音级。同一个 F♯ 放进 C 大调和 G 大调，结论就不同。

F♯ 与 F 在不同调式中的身份
实际音高按基本音级按当前调式
C 大调中的 F♯变音把原有的 F 升高，属于调式变音（♯Ⅳ）
G 大调中的 F♯变音F♯ 本来就是第Ⅶ级
G 大调中的 F♮基本音级把原有的 F♯ 降低，属于调式变音（♭Ⅶ）

因此 G 大调谱上的还原号可以写出调式变音 F♮。这里的还原号说明实际音高回到基本音级 F，♭Ⅶ 则说明它比这个调原有的第Ⅶ级低半音。

实际音高与音级标记

谱面的升、降、还原记号用来确定实际音高。音级标记中的升降号写在罗马数字左侧，表示该音比当前调式原有的同名音级高或低。例如 F 大调原有的第Ⅳ级是 B♭。把它升半音得到 B♮，谱面写还原号，音级仍记作 ♯Ⅳ。判断时要先从调号与上下文读出音高，再与当前音阶比较。

小调也按当前采用的音阶来判断。G♯ 相对于 a 自然小调是升Ⅶ级，在 a 和声小调里则是原有的第Ⅶ级。

典型调式变音

大、小调的第Ⅰ、Ⅲ、Ⅴ级组成主三和弦，在调式里统称稳定音，其中第Ⅰ级最稳定。不稳定的音向稳定音进行，叫作解决。典型调式变音把这种距离缩到一个半音，使解决的方向更明确。

例如 C 大调的 F、A 与稳定音 G 原本各隔一个全音。F 升为 F♯ 后，从 G 的下方半音趋向 G。A 降为 A♭ 后，从 G 的上方半音趋向 G。这两种变音的方向相反，解决到同一个第Ⅴ级。

辅助音与经过音

辅助音在两个相同音高之间形成一次离开与返回，与原音相隔上方或下方二度。经过音连接两个不同音高，旋律保持同一方向逐级经过中间音。一个经过片段可以有多个中间音，相邻音通常相隔半音或全音。

  • 自然辅助音、自然经过音使用当前调式音阶原有的音。例如 C 大调的 D 本来就是第Ⅱ级，所以表中两个以 D 为中间音的谱例都属于自然形式。
  • 变化辅助音、变化经过音使用升高或降低当前调式某个音级后得到的音。例如 C 大调的 D♭ 是降低的第Ⅱ级，F♯ 是升高的第Ⅳ级。它们都是调式变音。
C 大调中的自然与变化形式
角色自然形式变化形式
辅助音C–D–C C–D♭–C
经过音C–D–E F–F♯–G

同一个 F♯ 在 G 大调中是音阶原有的第Ⅶ级。它在 E–F♯–G 中是自然经过音，即使音名带升号。

副导音及其解决

在 C 大调里，第Ⅶ级 B 向主音 C 上行半音，B 因此是这个调的导音。通过调式变音，也能在其他稳定音周围临时形成类似的半音关系。

副导音产生临时的小二度倾向，目标可以是主音，也可以是其他稳定音。升高的音通常向上解决，降低的音通常向下解决。

C 大调中 D 升为 D♯，再上行至 E 。D 降为 D♭，则趋向下行至 C 。

导音倾向的反转
  • B 原本向上趋向 C，降为 B♭ 后可下行至 A。
  • F 原本向下趋向 E，升为 F♯ 后成为向上指向 G 的副导音。

调式半音阶

半音阶在一个八度内连续走十二个半音，连同两端共写十三个音。调式半音阶沿用原调式的主音与音阶骨架，在原有大二度之间补入一个音。自然大、小调各有五处全音、两处半音，所以需要补五个音。原来的半音位置保留，原有音级也保留它们的音名。

半音距离只决定实际音高，调式还决定这个音该怎样写。例如在 C 大调的 G 和 A 之间，G♯ 与 A♭ 的实际音高相同。上行把它写成升Ⅴ级 G♯，下行写成降Ⅵ级 A♭。表中的升Ⅳ级和降Ⅶ级在两个方向沿用同一种拼写。

调式半音阶的写法

D 大调半音阶的填音顺序

  1. 先写 D 自然大调的音阶。F♯–G 与 C♯–D 已经是半音，其余五处各留一个音的位置。
  2. 上行先确定降Ⅶ级 C，填在 B 和 C♯ 之间。其余空隙用升Ⅰ、升Ⅱ、升Ⅳ、升Ⅴ填入。下行先确定升Ⅳ级 G♯，填在 A 和 G 之间，再用降Ⅶ、降Ⅵ、降Ⅲ、降Ⅱ填入其余空隙。
  3. 核对填入的音和两侧原音各差半音。以下行的降Ⅲ级为例，D 大调的第Ⅲ级是 F♯，降低后得到 F♮，正好填在 F♯ 和 E 之间。结合调号记谱时，此处用还原号写 F。

a 小调半音阶的拼写

a 小调上行借用关系 C 大调的变音拼写。A 到 B 之间填 B♭，因为 B♭ 是 C 大调半音阶里的降Ⅶ级。下行按同主音 A 大调的下行拼写，同时保留 a 自然小调原有的音级。两种方法得到同一组音，上下行顺序相反。

  • D 大调上行的 C、C♯ 在同一小节和同一八度时，C 用还原号取消调号里的升号，随后用升号恢复 C♯。
  • a 小调下行的 G♯、G 在同一小节和同一八度时，G 用还原号取消前一个音的临时升号。
