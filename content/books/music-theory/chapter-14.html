第十四章　近现代乐理知识

本章介绍新的调式关系、音列构成方法和记谱方式，以及十二音序列的变形。

同中音调与重同名调

同中音调的中音（Ⅲ级）与下中音（Ⅵ级）分别相同，调式结构和主音不同。C 大调的 E、A 与 c♯ 小调的 E、A 相同，因此两者构成同中音调。

从这个同中音小调 c♯ 小调继续找它的同主音大调，就到了 C♯ 大调。C♯ 大调的自然音阶正好比原来的 C 大调整体高半音。这样把同中音与同主音两种关系各用一次，得到的调叫重同名调。调换两种关系的先后顺序，从 C 大调经过 c 小调，就会得到整体低半音的 C♭ 大调。

以 C 大调为核心的关系
关系连接路径
同主音C 大调 → c 小调
同中音C 大调 → c♯ 小调
重同名（降低半音）C 大调 → 同主音 c 小调 → 同中音 C♭ 大调
重同名（升高半音）C 大调 → 同中音 c♯ 小调 → 同主音 C♯ 大调

降半音的路径中，c 小调与 C♭ 大调共用 E♭、A♭ 两个中音。升半音的路径中，c♯ 小调与 C♯ 大调共用主音 C♯。

中古调式的合成

两个或多个中古调式的音列片段可以组合成一个合成音阶。利底亚与爱奥尼亚的合成谱用 a、b 标明两个片段。a 取利底亚的前五个音，b 取爱奥尼亚的前四个音。两段共用 C，所以接起来是八个音。

后两例给出完整的合成音阶。根据谱上的音程，可以同样从第Ⅴ级处分出上下两段。这里加上括线，便于比较三例各自用了哪些调式材料。

利底亚与爱奥尼亚

F 利底亚的前五音止于 C，C 爱奥尼亚的前四音从这个 C 接上。第Ⅳ级 B 保留了下段的增四度，第Ⅶ级 E♭ 则来自上段。两处半音在 B–C 和 D–E♭。

弗里几亚与伊奥尼亚

在 E 弗里几亚的第Ⅴ级 B 接入 B 伊奥尼亚的前四音，保留主音 E 上方的半音 E–F，同时让上方的 D♯ 以半音接到高八度 E。

多利亚与伊奥尼亚

在 D 多利亚的第Ⅴ级 A 接入 A 伊奥尼亚的前四音。第Ⅲ级仍是 F，第Ⅵ级为 B，第Ⅶ级成为 C♯。升高的第Ⅵ、Ⅶ级使这个音列与 D 旋律小调上行相同。

人工调式

人工调式是为创作需要组织出来的音阶。可以规定相邻音的距离，也可以把两种音阶的材料合到一起。全音音阶、合成大小调式和有限移位调式分别展示了这些方法。

全音音阶

一个八度有十二个半音。每次走一个全音，即两个半音，走六次就回到高八度，所以全音音阶只有六种不同的音高。任意两音之间相差偶数个半音，因此音阶中没有小二度、纯四度或纯五度。

从第一组的 D 起奏，会顺次用到同一组音。整组升高一个半音才得到第二组，再升一个半音就回到第一组。因此全音音阶只有两组不同的音高集合。

合成大小调式

C 自然大调和 c 自然小调共用主音以及第Ⅱ、Ⅳ、Ⅴ级。第Ⅲ、Ⅵ、Ⅶ级各有两个版本，合成时两种音高都保留。一个八度内共有十种不同的音高，谱例最后的 C 是主音的高八度。

有限移位调式

有限移位调式按固定的音程组合反复构成，梅西安将这种组织方法用于创作。整组移调时，一旦音程组合完整挪过一个周期，起点虽已改变，得到的仍是原来的一组音高。

重复音程型
组合半音数每隔多少半音回到原音集
半音＋全音1＋23
小三度＋半音3＋14
大三度＋大二度4＋26
全音＋半音2＋13

以 C 起奏半音＋全音，第一个三半音周期是 C–D♭–E♭ ，后续从 E♭ 再套用同一间隔。整组音上移一个半音或两个半音会得到新音集，上移三个半音便回到原音集，因此只有三组不同的移位音集。以 C 为起点交换半音和全音的次序，会得到三组移位之一。小三度＋半音每四个半音重复一次，大三度＋大二度每六个半音重复一次，分别有四组和六组不同的移位。

半音阶的其他记谱法

按进行方向拼写的简便半音阶

简便半音阶的上行填隙一律用升号，下行一律用降号。例如夹在 A 与 B 之间的音，上行写 A♯ ，下行写 B♭ 。第 11 章的调式半音阶在 C 大调中会把这个音统一写成 B♭。

上下行沿用同一拼写的和声半音阶

这种写法为每一个音高固定音名，下行把上行的音名次序倒过来。例如 C 与 D 之间固定写 D♭，上行是 C–D♭–D，下行是 D–D♭–C。还原号按调号和前面的临时记号决定，所指的音名保持一致。

十二音技法

十二音技法由勋伯格发展。它把一个八度内的十二种音高当作排序材料，每种音高在原型中出现一次。例如同名音高的不同八度仍算同一类，C♯ 和 D♭ 这样的等音也算同一类。排序确定各音的先后，节奏和八度可另外安排。

原型、逆行、倒影与逆行倒影

逆行从原型的最后一音向前读。倒影在这里保留首音，用它作为轴，把每个音相对首音的上方距离翻到下方，下方距离翻到上方。以 A 为轴，原型 的后两音比 A 高两个、三个半音，倒影便写成比 A 低两个、三个半音的 G、F♯ 。逆行倒影把倒影从末音向前读。

现代记谱法

现代记谱有的沿用五线谱，再补上更细的音高、时间或动作指示。有的用图形或文字规定演奏轮廓和范围。读这类谱时，谱例和图例共同决定哪些信息已经写定，哪些交给演奏者处理。

微分音

微分音记法可以标出小于半音的音高变化。把全音均分四份，每份是四分之一音，即 50 音分。均分六份时，每份是六分之一音，约 33.3 音分。也可叠加这些单位，比如用记号表示升高或降低 150 音分。不同作品的符号可能不同，读谱以图例为准。

音组、音块与不确定音

音组把规定的音或音型框起来，再规定反复的范围。方框中的音型 可一遍遍反复，直到箭头所示的结束处。谱上若在后面另给音型，则从对应位置换用新的材料。

音块是相邻音高密集地同时发声。黑块的上下边缘可表示最高音、最低音，向右延伸的部分表示持续，逐渐收窄则表示音域收缩 。谱面还可以指明只用白键、只用黑键，或用范围内连续的半音。如果另列指定音高，就按列出的音来奏。

不确定音给出大致的音区、最高或最低音、运动方向等条件，具体音高由演奏者选定。例如一条逐渐向谱表上部移动的线，规定了音高轮廓；方框音组则直接规定了反复的音型。

时值、速度与力度的图形

比例记谱可在音头后画横线 ，线越长，音持续越久。同组音也可用扇形符杠表示速度变化 ，符杠从汇合到展开表示逐渐加快，反向表示逐渐放慢。力度楔形进一步给出渐强或渐弱的方向，旁边的力度记号可以说明起点或终点。

键盘、弦乐、声乐与管乐的特殊记谱
  • 键盘乐器。斜向音块可以表示沿键盘刮奏。前臂压奏的音块也可以逐步缩小，最后只留一个音。手掌击打键盘侧面或琴台等木制部位时，谱会另用图示或文字注明击打部位。
  • 弦乐。滑奏颤音可同时改变音高并快速颤动。谱面也可指定用手指敲弦的位置、在琴马和弦钩之间用弓，或用弓根加重压力产生噪声。符号作用在几根弦上，须结合谱上标示。
  • 声乐。开口与闭口是对口形的指示。说话谱可以给出节奏，舌颤、唇击声和笑声则可以分别用文字或图形标明，音高可以按作品要求确定或留给演唱者。
  • 管乐。只按键时，叉形音头可以给出指法对应的谱位 ，实际发出的是键噪音。气颤、只吹气、用手掌或舌击吹口也可以分别标示，具体动作按作品图例区分。
