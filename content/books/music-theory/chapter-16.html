第十六章　律学常识

十二平均律、五度相生律与纯律采用不同的定音方法。同名音的实际频率可以略有差别。

十二平均律与音分

律制规定各音的音高关系。十二平均律把一个八度分成十二个相等的半音。在音分尺度上，一个八度是 1200 音分，平均律的一个半音是 100 音分。

音分以频率比计算。八度的频率比为 2∶1，十二平均律每升半音，频率乘以 2 的 112 次方。C 到 E 跨四个半音，为 400 音分。C♯ 和 D♭ 在十二平均律中是同一个音高，换到其他律制，等音拼写未必对应相同频率。

音分相加对应频率比相乘。连续两个八度的频率比是 2 × 2，也就是 4∶1，音程是 1200 + 1200＝2400 音分。计算两个音之间的音分差，只需用同一基准下的高音音分减去低音音分。

泛音列

弦发声时，全弦和它的各等分部分可同时振动。基音的频率记为 f，第 n 分音的频率为 n 倍的 f。基音是第一分音，第二分音起称为泛音。

不同分音混合成为复合音。分音的强弱分布影响音色。

用较高分音的频率除以较低分音的频率，可以得到定律常用的音程。第 3 分音与第 2 分音之比是 3∶2，第 5 分音与第 4 分音之比是 5∶4，分别是纯五度与纯律大三度。

分音编号与八度归并
  • 第一分音是基音，第二分音是第一泛音。两种编号相差一位。
  • 把第 3 分音移低一个八度，频率比从 3∶1 变为 3∶2。把第 5 分音移低两个八度，则得到 5∶4。这种移位保留音级，把音程缩进同一个八度。
  • 倍数相同的音程可以跨不同音区出现。例如第 3 到第 6 分音、第四到第八分音都相隔纯八度。

五度相生律

第二分音与第三分音的频率比为 3∶2。由一个音向上或向下连续取这个纯五度，再把各音归到同一八度，便得到五度相生律。

以 C 为主音，取向下一个五度和向上五个五度，得到 F–C–G–D–A–E–B。重排后得到 C 大音阶，其全音约 204 音分，半音约 90 音分。C–D–E–F 与 G–A–B–C 两组的间隔都是全、全、半。

从 C 向上连续取两个纯五度得到高区的 D，频率比是 9∶4。归低一个八度后变为 9∶8，约 204 音分。这是五度相生律的大二度。E 与 F 在同一基准下分别约为 408、498 音分，相差约 90 音分，称为古代小半音。

五度相生十二次的音差

一个五度相生的纯五度约为 702 音分，比平均律的 700 音分宽约 2 音分。十二个纯五度减去七个八度，余约 23.46 音分，常近似记作 24 音分。

纯律

纯律除了采用 3∶2 的纯五度，还使用第四分音到第五分音形成的 5∶4 大三度。以 C 大调为例，可在 F–C、C–G、G–D 三个纯五度内分别加入 A、E、B，构成三个大三和弦。

纯律 C 大音阶有约 204 音分的大全音、约 182 音分的小全音和约 112 音分的大半音。D–A 的五度仅约 680 音分，称为狭五度。

同一基准下，纯律的 E、A、B 比五度相生律的同名音各低约 21.51 音分，近似记作 22 音分，称为普通音差。

五度相生律与平均律的比较

在十二平均律中，B♯、C、D𝄫 归到同一个键。按五度相生律由 C 向上连续取十二个五度，所得 B♯ 归到同一八度后比 C 高约 23.46 音分。反向连续取十二个五度所得 D𝄫 比 C 低约 23.46 音分。
