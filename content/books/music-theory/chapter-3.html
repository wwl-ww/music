第三章　音的高低

这一章从钢琴键盘出发，先认识音名和音高，再学会把同一个音写在不同的谱表上。

音列与音级

发声物体振动得越快，音通常就越高。每秒振动的次数叫频率，以赫兹（Hz）为单位。调音常用的标准音 A4 是 440 Hz。

音乐中有固定音高的乐音合起来，构成乐音体系。按音高把这些音排起来，就得到音列。音列中的各个音叫音级。钢琴的白键反复使用七个基本音级 C、D、E、F、G、A、B。

字母是音名。音名加上音组才能标明具体高度，例如 C4 和 C5。do、re、mi、fa、sol、la、si 是唱名，在首调唱法里随调改变。下面用 C 作 do 来对照。

半音的计算

相邻两个琴键相隔一个半音，两个半音合成一个全音。E–F 和 B–C 之间没有黑键，所以各隔半音。其余相邻白键各隔全音。一个八度包含十二个半音。

音列分组

标准 88 键钢琴有 52 个白键，音名循环使用。为了区分名字相同、音高不同的音，以 C 为每一组的起点，到 B 结束。中央 C 是小字一组的第一个音，写作 c¹，也常写作 C4。标准音 A4 是同组的 a¹。

C3、C4 和 C5 的音名相同，相邻两个音相隔一个八度。简谱用数字上下的圆点区分八度，五线谱用符头的高度区分。

88 键钢琴的两端是不完整的音组，最低键是 A0，最高键是 C8。

变音、等音与音名的拼写

把基本音级升高或降低，就得到变化音级，简称变音。谱面上用变音记号写明变化。

五种变音记号
名称记号作用
升号升高一个半音
降号降低一个半音
还原号恢复为基本音级
重升号升高一个全音
重降号降低一个全音

临时变音记号在本小节内对同一谱位后续出现的音继续有效，遇到新的变音记号时以新记号为准。下一小节重新按该处的调号读。

在十二平均律的钢琴上，C♯ 与 D♭ 落在同一个键，音高相同，音名及写法不同。这种关系叫等音。等音也可以落在白键上，例如 E 与 F♭。若只用单升降和重升降，一个八度内通常每个键有三种常见拼写，G♯／A♭ 这个键只有两种。

C♯ 和 D♭ 在五线谱上占不同位置 ，在钢琴上使用同一个键。

半音与全音的分类

一对音是半音还是全音，由它们之间的音高距离决定。它是自然还是变化，要看两端字母代表的基本音级。相邻字母是自然的，同一字母或隔开一个字母是变化的。

半音与全音的记法
类别例子为何这样归类
自然半音E–F、C–D♭相邻字母，相隔一个半音
变化半音C–C♯、E♯–G♭同一字母，或中间隔一个字母
自然全音C–D、E–F♯相邻字母，相隔两个半音
变化全音D–D𝄪、E–G♭同一字母，或中间隔一个字母

例如 C–C♯ 和 C–D♭ 在键盘上走的是同一步。前者两端都用字母 C，后者用相邻的 C 和 D，因此分别是变化半音和自然半音。

五线谱与加线

五线谱的五条线和四个线间都从下往上数。音符可以写在线上或线间，每移动一个位置，就跨一格基本音级。写到五线外时，使用与谱线等距的加线。加线之间也能放音。

加线与加间的编号
  • 上加线和上加间向上数，下加线和下加间向下数。基本谱线与第一条加线之间就是加一间。
  • 加线只写在需要它的音符附近。相邻音符各用自己的加线，避免连成新的长谱线。加线理论上可继续增加，实际记谱通常不会用太多。

谱号与音高

同一个谱位的音高，由每行左端的谱号确定。谱号先指定一条线的音高，再沿线与间逐级推算其他基本音级。

谱号图形定位

F 谱号（低音）两点夹住第四线 F3

C 谱号（次中音）中心对准第四线 C4

中央 C 在各谱号中的位置

高音谱表下加一线与低音谱表上加一线都表示 C4。在中音谱表和次中音谱表上，中央 C 分别写在第三线和第四线。

  • 高音谱号
  • 低音谱号
  • 中音谱号
  • 次中音谱号
谱号的更换
  • 选用接近实际音区的谱号，可减少加线。曲中可以换谱号，例如大提琴进入较高音区时可改用次中音谱号。每行开头都要标当前谱号。
  • C 谱号的中心还可以定位第一、二、五线，分别称女高音、次女高音、上低音谱号。这些位置较少见。

谱表的类型

五线加上谱号成为谱表。单谱表只有一行 。高音谱表常见于小提琴、长笛等乐器；低音谱表常见于大提琴、大管等乐器；中音谱表常见于中提琴。乐器跨入另一音区时，也可能临时换谱号。

高音和低音谱表合成大谱表 。钢琴、风琴和手风琴常用花括号连接两行。上方的下加一线与下方的上加一线都表示中央 C。

联合谱表把不同声部的谱表上下排列，让同一时刻的音纵向对齐。例如独唱和钢琴伴奏可以排成三行 。合唱或重奏也常用方括号连接多行谱表。

联合谱表的常见编排
  • 独唱加钢琴通常把独唱谱表放在上面，钢琴大谱表放在下面。
  • 弦乐四重奏常按第一小提琴、第二小提琴、中提琴、大提琴排列，依次使用高音、高音、中音、低音谱表。
  • 混声四部常按女高音、女低音、男高音、男低音排列。男高音可用低八度记读的高音谱号。
