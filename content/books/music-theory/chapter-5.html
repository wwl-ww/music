第五章　调式、大调式

调式由主音和各音之间的关系构成。自然大调的第Ⅰ级与第Ⅲ级构成大三度，各调沿用同一套音阶结构。

调式、主音与音阶

若干音按一定关系围绕一个中心音组织起来，形成调式。中心音称为主音。调式可以包含不同数量的音，常见的有五声调式和七声调式。大小调体系包括大调、小调及两者相互影响产生的变体。

从主音到相邻八度的另一个主音，把调式里的音按音高依次排列，就得到音阶。音阶可以上行或下行，按相邻音的距离可以比较不同调式的结构。

自然大调的全音与半音

自然大调包含七个音级，相邻音的距离依次是全、全、半、全、全、全、半。在 C 大调里，两个半音分别是 E–F 和 B–C，C–E 相隔四个半音，构成呈现大调色彩的大三度。

音级名称C 大调至上方一级
Ⅰ主音C全音
Ⅱ上主音D全音
Ⅲ中音E半音
Ⅳ下属音F全音

属音位于主音上方纯五度，下属音位于主音下方纯五度。Ⅰ、Ⅳ、Ⅴ级合称正音级，构成调式的骨架。中音在主音与属音之间，下中音在下属音与上方主音之间。上主音和导音分居主音上下，相邻时都有趋向主音的倾向。Ⅱ、Ⅲ、Ⅵ、Ⅶ级合称副音级。

大调的调名与调号

调名由主音和调式共同确定。把 C 大调换到另一个高度，主音变了，音阶仍要保持「全、全、半、全、全、全、半」。因此，半音要随主音移到新的位置。

从 D 排白键，半音落在 E–F 和 B–C。D 大调需要半音落在第 Ⅲ–Ⅳ 级和第 Ⅶ–Ⅰ 级，也就是 F–G 和 C–D 的位置。升高 F 和 C，半音就移到了 F♯–G 和 C♯–D。

把 F♯、C♯ 集中写在谱号右侧、拍号之前，就得到 D 大调的调号。第三行的音符前省去升号，奏出的音高和第二行相同。简谱用 1＝D 标明主音。

升号与降号的产生

把自然大调分成两组各四个音。两组内部都是全、全、半，中间隔一个全音。

C 大调的两组四音
下方四音两组之间上方四音
C–D–E–FF–GG–A–B–C
全、全、半全音全、全、半

两组可以接到相邻的大调里，因为它们的内部结构一样。

向上纯五度：C 大调到 G 大调

把 C 大调上方的 G–A–B–C 作为 G 大调的下方四音。接上的 D–E–F–G 末尾是全音。把 F 升为 F♯，E–F♯ 变成全音，F♯–G 变成半音。

向下纯五度：C 大调到 F 大调

把 C 大调下方的 C–D–E–F 作为 F 大调的上方四音。接在前面的 F–G–A–B 末尾是全音。把 B 降为 B♭，A–B♭ 变成半音，两组之间的 B♭–C 变成全音。

同一步骤推到下一个调

G → D 时，共用 D–E–F♯–G，原来的 F♯ 保留。新接的 A–B–C–D 把 C 升为 C♯。

F → B♭ 时，共用 F–G–A–B♭，原来的 B♭ 保留。新接的 B♭–C–D–E 把 E 降为 E♭。

调号记号的固定顺序

升号 F♯、C♯、G♯、D♯、A♯、E♯、B♯。从 C 大调出发，每多一个升号，新主音就比前一调高一个纯五度。原有升号保留，新增的是新调的第 Ⅶ 级。

降号 B♭、E♭、A♭、D♭、G♭、C♭、F♭。从 C 大调出发，每多一个降号，新主音就比前一调低一个纯五度。原有降号保留，新增的是新调的第 Ⅳ 级。两列音名字母的顺序正好相反。

由调号判断大调主音

升号调最后新增的是第 Ⅶ 级，向上半音就是主音。三个升号的最后一个是 G♯。谱上 G♯ 到 A 相邻，主音是 A。

降号调每次用前一调的第 Ⅳ 级作新主音。前一调最后加的降号，在新调里就是倒数第二个。调号 B♭、E♭ 中，B♭ 是倒数第二个，主音就是 B♭。一个降号时是 F 大调。

调号中的 E♯、B♯、C♭ 与 F♭

大调的七个音级依次使用七个不同的字母。琴键可以相同，音名要按音级的位置来写。

  • E♯ 与 F 同键。F♯ 大调的第 Ⅶ 级用字母 E，写作 E♯。
  • B♯ 与 C 同键。C♯ 大调的第 Ⅶ 级用字母 B，写作 B♯。
  • C♭ 与 B 同键。G♭ 大调的第 Ⅳ 级用字母 C，写作 C♭。
  • F♭ 与 E 同键。C♭ 大调的第 Ⅳ 级用字母 F，写作 F♭。
高音与低音谱表的调号位置

换谱号后，同名音所在的线或间会变，记号从左到右的顺序相同。升号用中间的小方格对准线或间，降号用弧部的中心对准。

升号、降号和还原号的字形来历

中世纪欧洲圣咏用两种 b 区分 B 的两种音高。

  • 圆形 b 表示较低的 B，字形演变为降号 。
  • 方形 b 表示较高的 B，可以取消先前的降低。这个字形后来演变出还原号  和升号 。

等音调与五度循环

两个同类调式的各级音分别等音时，它们互为等音调。调号在七个升降号以内时，大调有三对等音调。每对调的音阶使用同一组琴键，各级的音名和调号写法有别。

七个升降号以内的三对等音大调
升号一侧降号一侧
B 大调 C♭ 大调
F♯ 大调 G♭ 大调
C♯ 大调 D♭ 大调

顺着纯五度向上排列主音，借助等音调可以连成五度循环。以 C 大调为起点，顺时针经 G、D、A，依次增加升号。逆时针经 F、B♭、E♭，依次增加降号。相邻大调共有六个音，下方三个扇区各有两种等音写法。

稳定音、不稳定音与解决

大调的Ⅰ、Ⅲ、Ⅴ级是稳定音，其中主音最稳定。Ⅱ、Ⅳ、Ⅵ、Ⅶ级是不稳定音。以 C 大调为例，D 可走向 C 或 E，F 可走向 E，A 可走向 G，B 可上行到 C。

含不稳定音的不协和音程进行到由稳定音组成的协和音程，叫作解决。稳定音可以保留，也可以移到其他稳定音，不稳定音通常就近进行。增音程向外解决到较大的音程，减音程向内解决到较小的音程。

C 大调的 F–B 向外解决到 E–C，增四度扩为小六度。B–F 向内解决到 C–E，减五度缩为大三度。

首调唱名与固定唱名

首调唱名按调式中的音级分配唱名。大调主音唱 do，从 Ⅰ 到 Ⅶ 依次是 do、re、mi、fa、sol、la、si。C 大调的 do 是 C，G 大调的 do 是 G。简谱采用首调唱名。

固定唱名按字母音名分配唱名，C 固定为 do，D 固定为 re，其余以此类推。升降记号改变唱出的实际音高。D 大调中的 F♯ 唱 fa，实际音高比 F 高半音。

B♭ 大调的五线谱译作简谱

在 B♭ 大调中，B♭ 是 1。第一小节的 F4、D5 分别记为 5 和高音 3。第三小节的四个八分音符仍按两拍分组。
