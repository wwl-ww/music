第九章　调的关系

调之间的关系可以从调号、主音、宫音和音列判断。关系大小调与同主音大小调分别采用不同的参照。

关系大小调

关系大小调的调号与主音

两调共用调号。小调主音在大调主音下方小三度，是大调的第Ⅵ级。

自然大调与关系自然小调使用相同的音级，从各自的主音排列成音阶。

大小调体系中的近关系调

在大小调体系中，主调有五个近关系调：主调的关系调、属调和下属调，以及属调和下属调各自的关系调。表中列出这五个调和主调本身。

以 C 大调或 a 小调为主调的近关系调

无升降号C 大调a 小调
一个升号G 大调e 小调

以 C 大调为主调，a 小调是关系调，G 大调和 F 大调分别是属调和下属调，它们各自的关系调是 e 小调和 d 小调。以 a 小调为主调时，e 小调和 d 小调分别是属方向和下属方向的近关系调。

近关系调的主和弦

这些调的主和弦都可由主调的自然音级构成。例如 C 大调中的 C、Dm、Em、F、G、Am 三和弦，分别是六个调的主和弦。

同宫五声调式

同宫五声调式共用宫音、音列与调号，各有自己的调式主音。C 宫系统的音列为 C、D、E、G、A。

五声调式的近关系调

五声调式的近关系范围包括主调所在的宫系统，以及宫音向上、向下纯五度的两个相邻宫系统。三个系统各有五种调式，去掉主调本身，共有十四个近关系调。

若主调是 F 宫系统中的调式，则取 B♭、F、C 三个相邻的宫系统。系统以宫音确定，主调可以是该系统的五种五声调式之一。

相邻宫系统的五声音列有四个共同音。以 C 宫系统为例，宫音向下移纯五度到 F 时，E 换成 F。向上移纯五度到 G 时，C 换成 B。

同主音大小调式

同主音大小调是以同一音高为主音的一对大小调。从 C 大调出发，它的同主音小调是 c 小调。从 c 小调出发，它的同主音大调也是 C 大调。两调都以 C 为第Ⅰ级。

自然大调与自然小调的音级差异

以同一个主音为起点，自然小调的第Ⅲ、Ⅵ、Ⅶ级各比自然大调低半音，第Ⅰ、Ⅱ、Ⅳ、Ⅴ级相同。第Ⅲ级的变化使主音到第Ⅲ级的音程由大三度变为小三度，主三和弦也随之由大三和弦变为小三和弦。

上行红色的 C 是大调的第Ⅰ级，首尾相隔一个八度。下行把第Ⅲ、Ⅵ、Ⅶ级的降号直接写在音符前，便于逐级对照。

同主音大小调的调号差

两调的调号相差三个升降号。由大调找同主音小调，沿五度圈向降号方向移三格。

每移一格就多一个降号，或少一个升号。C 大调无升降号，c 小调有三个降号。G 大调有一个升号，向降号方向移三格先抵消这个升号，再增加两个降号，因此 g 小调有两个降号。在传统调关系分类中，同主音大小调通常归入远关系。

同主音五声调式

同主音五声调式共用同一个调式主音。这个音可以分别担任宫、商、角、徵、羽。它担任的音级一变，所属的宫系统也随之改变，音列和调号就会不同。

由主音和调式确定宫音

商、角、徵、羽分别在宫音上方的大二度、大三度、纯五度、大六度。已知主音和调式，就按对应音程向下找宫音。比如 C 徵的 C 是徵音，向下找纯五度得到 F。取 F 宫系统的五个音，从 C 开始排列，得到 C–D–F–G–A。调号沿用 F 大调的一个降号。
