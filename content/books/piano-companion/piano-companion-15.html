第十五章 大调副属和弦的处理手法

全曲留在大调时，ii、iii、IV、vi 可以在乐句中短暂变成解决目标。副属和弦先给目标增加导音，随后原调的功能继续进行。实际编配要同时检查目标、升降音和旋律在该拍的落点。

副属三和弦、副属七和弦与解决

在 C 大调里，Am 是 vi。E7 的 G♯ 把 A 临时变成有导音的目标，D 则是 E7 的七音。进入 Am 时 G♯ 上行到 A，D 通常下行到 C。这里的 V7/vi 中，斜线后写临时目标。和弦符号 E7/G♯ 的斜线后写实际低音。

C 大调中的临时目标与副属和弦
目标属三和弦与属七临时导音
Dm（ii）A、A7C♯ → D
Em（iii）B、B7D♯ → E
F（IV）C7E → F，B♭ → A
Am（vi）E、E7G♯ → A

副属三和弦可以在高潮独立着色，属七也可以形成局部阻碍式。两种写法都要看后续低音和趋向音是否有落点。副导七和弦的音响更紧，通常明确解决到它所指向的和弦。

同一句中的连续临时属—主

旋律在原有拍点推进，低音沿调内根音移动。

大调六级的副属和弦

E7–Am 给 vi 一个关系小调式的局部收束。C、F、Dm、G、Em 或 Am 自身都能作为 E7 的来处。进入前若密集中有 G，自然 G 与 G♯ 可以先后形成半音，也可分开音区，以免两个相邻音同时挤在中高声部。

E7→F 是 Am 局部空间里的 V7→VI。低音 E–F 走半音，G♯→A，D→C 仍各有去处。接下去若是 Dm–G7–C，整句仍以 C 大调结束。G♯–B–D–F 构成 G♯°7，也可直接引向 Am。

E7 的正常解决与阻碍走向

低音 E 跳向 A，内声 G♯、D 分别进入 A、C。

大调二级的副属和弦

A7 的 C♯ 指向 Dm 的根音 D，G 向下到 F。C♯–E–G–B♭ 构成副导减七和弦 C♯°7。Dm 常继续进入 G7–C，于是局部解决和整句回主各有一层。F、Em、Am、C 或 G 都可以接到 A7，再转入 Dm。

旋律在该拍停 C 时，A7 的 C♯ 与 C 如果挤在同一音区会削弱线条。可以推迟 A7 到旋律 C 已离开的位置，或保留调内 Am。开阔的高潮也可把 A 大三作为色彩独立用，靠之后的和声恢复调中心。

同一终止前的 Am 与 A7

Am 到 Dm 保留调内色彩，句末由 G7–C 收束。

大调四级的副属和弦

C 和 C7 的根、三、五音相同。C 当主三和弦时可以停住，加入 B♭ 后形成 C7。E–B♭ 的三全音在 F 大三里收拢成 F–A，因而 C7 可以在下一段由 IV 起头时把两段接起来。它也可插在句中，原来 C–F 的拍点可以保持，只在 F 之前把 C 改成 C7。

C7 也能类比 F 大调的阻碍进行走向 Dm，F 与 A 仍承接 E 与 B♭。E–G–B♭ 作为副导三和弦可直接指向 F，扩展到副导七时用 D 或 D♭ 区分半减与全减色彩。

同一段落接缝的 C 与 C7

C–F 从主功能走向下属功能，前一段的结束感仍在。

大调三级的副属和弦

B7–Em 用 D♯→E、A→G 把 iii 暂时抬到前景。Em 回接到 Am、F 或 Dm 时通常仍在 C 大调的功能环境中。B7 也能沿 Em 的阻碍走向去 C，D♯ 可以进入 C 和弦的 E，低音 B 则级进到 C。

D♯–F♯–A–C 是 D♯°7，根音 D♯ 同样清楚指向 E。旋律需要 F 自然音时，F♯ 常要挪到旋律离开之后，或改用较简单的调内和弦，使半音有可辨的去向。

B7 后的 Em 与 C

低音 B–E 确立 Em 的局部落点，D♯ 走到同音区的 E。
