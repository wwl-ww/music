第十七章 民族调式歌曲的伴奏手法

五声性旋律最重要的是保住主音和骨干音。和弦、低音和填充声部都可支持同一个调式中心，各自的选音和运动幅度有所不同。

民族调式的音列与主音

宫、商、角、徵、羽是一组骨干音的名称。以 C 为宫时，音列是 C、D、E、G、A。五个音都可成为主音。音列里两个小三度是 E–G、A–C，同一组音按不同中心排列，听到的五度、三度与六度关系也会改变。

同一宫系统的五种中心
调式从主音起的音列主音上方的特征音程
宫C D E G A大三度、大六度
商D E G A C小七度，缺三度
角E G A C D小三度、小六度、小七度
徵G A C D E大六度，缺三度
羽A C D E G小三度、小七度

找主音可先从反复出现的两组小三度识别宫系统，再结合长音、句尾和低音判断中心。曲中几句若分别落 G 或 A，还需要看哪一个最后稳定全段。骨干之外加入偏音可以形成六声与七声音阶。

雅乐、清乐与燕乐七声音阶
  • 雅乐在 C 宫骨干上加变徵 F♯ 和变宫 B。
  • 清乐在相同骨干上加清角 F 和变宫 B。
  • 燕乐在相同骨干上加清角 F 和闰 B♭。

同一组骨干音在 C 与 A 上收束

句尾 C 与 C 低音重合，E 成为主音上方的大三度。

民族调式的和声选择

低音和和弦以骨干音组织，功能关系随旋律展开。连续的属—主或四五度推进会增强西方功能感，适合需要明确终止的段落。用二、四度换掉传统三音，可以保留根音和五度方向，同时减弱大、小三和弦的区别。

C 宫中的 F 是偏音。F–A–C 可在需要下属色彩时出现，旋律强调骨干时可选 Dm 或 Am，也可省去支撑声部中的 F。大三和弦加入 D 或 A 可以扩大五声色彩，例如 C–E–G 加 D；小三和弦上加入四度或七度，例如 Am 加 D 或 G，也可保持五声骨干。新增音先与旋律比较，半音碰撞应有明确诉求。

调式中心容易游移时，句尾旋律和低音共同落到主音，常比延长一串强功能和弦更清楚。

三度和弦与五声性加音

中段 F 作为低音，制造明确的下属方向。

五声性的低音与织体补充

长主音低音提供中心，五声低音线能在段内继续运动。同一片段把 E–G 或 A–C 用在低音，常比经过一个新半音更贴合原旋律的语汇。上声部停留长音时，内声可以用五声短句回填；上声部密集时，低音应减少起音和音域跳跃。

上下声部都用五声音集仍可能互相抢拍。补充短句宜安排在上声部长音或休止，末音接到下一拍的和弦或低音支点。

长低音与五声低音回应

旋律负责所有的走向，低音明确每小节的支点。
