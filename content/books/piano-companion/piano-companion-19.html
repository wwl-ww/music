第十九章 常用特色和弦的应用介绍

色彩和弦可以改变一个内声、替换一个下属和弦，也可以在原来的终止前插入新落点。用同一句旋律对照不同配法，能听见改变来自哪一条低音或半音线。

大调重属和弦的色彩用法

C 大调的重属三和弦是 D–F♯–A。典型走向 D→G 让 F♯ 上行到 G。重属也可作为色彩出现，例如 D→Dm→G，F♯ 回到 F。D→F 时共同音 A 保持，F♯ 可以下行到 F。声部走向不同，听觉也就从局部属功能转到同根或半音色彩。

D 大三和弦接 G 或 Dm

F♯ 上行到 G 的趋向由属功能承接。

大调重属导七和弦

在 C 大调里，F♯–A–C–E♭ 构成 F♯°7，F♯ 是属音 G 的导音。它可以直接到 G，也可先过终止四六 C/G，再到 G7。C/G 在这里由 G 支持，常以 C→B、E→D 收进属和弦。

重属导七后直入属或经过终止四六

F♯ 到 G，第二小节直接出现属的三音 B。

大调下属大七和弦

Fmaj7 由 F–A–C–E 构成。E 可向 F 解决，也可与下一个和弦形成共同音。向 Em、C/G 过渡时可以保留 E，进入 ii 或属功能时可把 E 逐步下行，避免让新加的七音突然消失。若旋律正强调近距离的 F，E 放到低一点的中声部会更清楚。

F 上保留或加入内声 E

上声部保持，低音 F–E–D–C 逐级下行。

大调小下属和弦

C 大调的 iv 是 Fm，来自同主音小调。F–A–C 变为 F–A♭–C 时，只改一个音便形成 F→Fm→C。A→A♭→G 是最清楚的内声线。Fm 也可先走 G7 再回 C，或作为已回主之后的补充终止。

变格结尾中的 F 与 Fm

下属和弦持续到回主前。

大调二级半减七和弦

Dm7 是 D–F–A–C，借用同主音小调的 A♭ 后成为 Dø7。它可以放进 iiø7–V7–I，A♭ 下行到 G，F 可作为 G7 的七音保留。若回主后再短暂加入 Dø7 再回 C，能形成补充终止色彩。

同一 ii–V–I 中的 A 与 A♭

四个和弦音都来自 C 大调。

大调降六级和弦

C 大调借用的 ♭VI 是 A♭–C–E♭。当 G7 转到 A♭ 时，B 仍可到 C，但低音 G 改走上方半音。A♭ 再到 C 时，共同音 C 可以保持，A♭→G 与 E♭→E 形成反向半音。A 小三和弦转到 A♭ 大三时，也可利用低音 A→A♭ 和共同的 C。

G7 后回主或绕行 A♭

第二小节已经回主。

大调降七级和弦

C 大调里的 B♭ 大三来自同主音自然小调。I→♭VII 可以让低音向下走全音。B♭ 与 Am 相邻时，根音由 B♭ 下行到 A；接 G7 时可保留 F，再进入属七。B♭ 与大调导音 B 同时出现时，应安排音区或错开时值。

C 到 Am 之间的 G 或 B♭

低音先走属音 G 再到 A。

大调降三级和弦

C 大调从同主音小调借用 E♭ 大三时，C 与 E♭ 和弦共用 G。低音从主音跳到 E♭，可以再去 F，组成 I–♭III–IV；也能由 E♭ 转入 Am，随后经 ii、V 回到主。E♭ 与 E 自然音的分配应跟随旋律重音。

共同顶音 G 下的 C 与 E♭

第二小节保留主和弦。

小调大下属和弦

a 小调的 iv 为 D–F–A。提高六级 F 成 F♯ 后成为大下属 D–F♯–A。这种音响可来自同主音大调，也能出现在小调上行的六、七级语境。它可以走回 i、走向小属 Em、走向 E7，也可接 F。旋律有长 F 自然音时，可保留 Dm 或把 F♯ 放在后面的空位。

a 小调中的 Dm 与 D

下属和弦沿用小调的 F 自然音。

小调降二级和弦

a 小调的 ♭II 是 B♭–D–F。B♭ 是主音 A 上方的小二度，可联系 A 弗里几亚音列。♭II 可以放在 i 两侧形成色彩，也可作为属前准备。例如 B♭/D→E7→Am 让低音 D–E–A 方向明确，B♭ 在内声可经 B 到 C，或根据布置向 A 解开。

同一句中的 Dm 与 B♭/D

第二小节用通常的下属和弦。
