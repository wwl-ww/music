主题配色

第三章 和声选配基础

给旋律选和弦，先认出乐句哪里停顿、哪里结束，再判断哪些音真正支撑和声。一段伴奏的方向、密度与终止通常可以在弹开音型前确定。

和声功能及其基本进行规律

主功能 T 提供稳定中心。下属功能 S 把音乐带离主区并准备下一段进行。属功能 D 借助趋向主音的导音形成明显张力。以 C 大调为例，C、F、G 分别是这三类的正三和弦。F 和 G 的根音分居 C 下方与上方的纯五度。

T–S–D–T 是稳定、离开、加紧、回归的一条典型路线。实际句子可以从属区开头，也可以只用 T–D–T。G7 的 B 倾向升至 C，F 倾向降至 E，根音 G 回 C 把这两个方向归到同一个目标。A 小调里的 E7 以升高七级 G♯引向 A，具备对应的属功能。

和声终止式及其运用

终止式用和弦的临时停顿或解决标出结构。乐句内部可以在属上停住，较完整的段落尾声常回到主和弦。两处用不同的落点，才能听见句法层次。

终止的落点与常见准备
类别常见走法结构用途
半终止T–D、S–D、ii–D、vi–D、DD–D；也可用 T–S停在属功能的正格半终止留出后续预期。停在下属的变格半终止张力较缓。
全终止D 或 D7–T；S–T；S–D7–T属到主是正格，S–T 是变格。复式全终止由属前经过属回主。
补充终止T–S–T、T–s–T 或 T–♭VI–T先有一次收束，再添一个短尾声，重复确认主功能。
阻碍终止D7–vi，也可到带六级音的其他和弦导音可以解决，但低音改去预期主音以外的目标，乐段由此扩充。

DD 是属的属，例如 C 大调的 D7 指向 G。ii、vi、DD 都能放在 D7 前面，属前材料因旋律和句法而异。主和弦第二转位若出现在终止处，记作 K64。它保留属低音，上面的六度、四度分别降到五度、三度。K 通常放在比后续属和弦更强的拍位，延长属功能准备。

和声外音及其处理手法

同一拍的旋律音可能属于当时的和弦，也可能只负责连接、装饰或延缓解决。判断外音时，要看它从哪里来、到哪里去，再看它落在强拍还是弱拍。

常用和声外音的来去
类型判断依据在 C 和弦附近的示意
经过音以级进连起两个不同的和弦音。C–D–E 中的 D。
辅助音从一个和弦音走到相邻音并回原音。E–F–E 中的 F。
换音连起两个不同的和弦音，一侧级进，另一侧跳进。E–D–G 中的 D。
先现音后一个和弦的音在前一个和弦末尾先出现。G7 上先出现 C，随后进入 C 和弦。
延留音前和弦的音延续到后和弦强位，再级进解决。G7 的 F 延到 C 低音上，然后 F→E。
倚音强位的外音缺少同音准备，一般级进解决。C 和弦上的强位 D 下行到 C。

短弱位的外音通常可以跨在原和弦上。遇到强位外音，选配常依据紧接的解决音。按这里的基础写法，外音与解决音应相邻。如果强位的长音直接跳走，先重新判断和弦或功能，避免把选配的冲突一律视为装饰。

同一 F→E 的延留与倚音

F 从前一小节悬到新的 C 低音上，第一拍不再次触键。

选择和弦的八个基本原则

  1. 音的归属。 找小节内多数稳定音指向的和弦，先把短装饰音与和弦音分开。
  2. 重音。 强拍、拍内强位与长音，通常比一闪而过的音更能说明和弦。
  3. 功能走向。 选配怎样进入、离开主区。基础连接里，属和弦后的下属需要有清楚的动机。
  4. 跳进。 同一小节内相隔较远的几个旋律音有时本就是一组分解和弦，先找共同的骨架。
  5. 色彩。 多个和弦可托住同一个音时，可以保留基本功能，再改变和弦的明暗或紧张度。
  6. 和声节奏。 决定和弦在多少拍后变化，旋律的一串短音可以共享一处和声。
  7. 结构部位。 结尾常比段中更需要属的准备，即便同一旋律音也能用主和弦。
  8. 和声力度。 选择和弦的远近、强弱，让情绪逐步撑起，或留给收束处最清楚的解决。

多数音和强位若支持不同候选，句子处在开头、途中还是终点，往往成为最后的判断依据。色彩和力度的选择可以在基本走向成立后再细化。

和声节奏的安排原则与基本和声布局

和声节奏是换和弦的频率。快而旋律繁密的乐句可以两小节甚至更久才换一次。较慢、长音较多的乐句可按照一小节或半小节变化，需要局部推进时也可缩到每拍一个。速度只是初步线索，和弦何时变化还取决于旋律与结构。

开头通常用主、属等正三和弦尽快建立调性，下属开头相对少见。短弱起可让旋律先单独出现。内部句尾可以停在 D，也可以用 DD–D 指向属区，若要保留开放感，优先考虑属三和弦。段落末用 D7–T 明确收束，必要时再接补充终止。

换和弦通常从强位开始。和弦由弱位提前且跨过下一强拍，就会产生和声切分，适合有意制造提前感的地方。基础编配可先保持段落支点清楚，再安排这种例外。D→S 也可以作为有意的反功能色彩，用前后的旋律走势与终止支撑。
