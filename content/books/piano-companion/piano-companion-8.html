第八章 大调完全功能和声体系的即兴伴奏

大调的 I、IV、V 能建立主、下属、属三种功能。加入 ii、iii、vi、vii° 后，同一种句法可以有不同的低音与明暗层次。编配时从乐句的落点向前安排，分辨哪些地方需要明确解决，哪些地方适合保留共同音或改变低音路线。

和声力度及其处理手法

和声力度是两个和弦相接时感到的推进强弱。少有共同音、后一个根音尚未出现、或两个和弦都是正三和弦，通常会让变化更鲜明。共同音越多，越容易把两次和声听成同一功能区内的延伸。这些判断针对和弦连接，实际听感还受拍位、低音和声部排列影响。

共同旋律下的下三度与上四度

C 与 Am 共用 C、E，调性仍在主区，之后 ii–V7–I 才加快推进。

副三和弦的常用手法

副三和弦可替换同功能组的正三和弦，例如 ii–V 取代 IV–V。也可接在正三和弦之后延伸功能，例如 I–vi、IV–ii、V–iii。多组下三度连接可组成 I–vi–IV–ii。若要显出关系小调，ii–iii–vi 在 A 小调里可以读作 iv–v–i。

相似或重复的旋律可以改变配和弦。C、E 是 I 与 vi 的共同音，长 C 或 E 适合在两个根音之间转换。旋律是 A、C 时，vi 与 IV 都可承托。选择时要把整句的落点算进去。减少和声改动可保留旋律的辨识度，把变化集中在第二次出现的位置。

调内三度与借用三度

I 到 vi 改变的是调内和声。I 到 ♭III 则会出现同主音小调的色彩，在 C 大调中用 E♭ 替换 E。这样的色彩替换需要旋律允许 E♭，或避开和它相邻的 E 长音，后续也要交代回到原有中心的方法。

重复乐句的 I 与 vi

前两小节旋律与和声都原样返回，低音持续指向 C。

大调二级和弦

ii 是由第 2、4、6 级构成的小三和弦，属下属功能组。它可接在 I、vi 或 IV 后，随后直接去 V，也可经重属再去 V。以 4 级作低音时得到 ii 的第一转位。C 大调中的 Dm/F 与 F 大三共享 F、A 和低音 F，常用来替代终止前的 IV。

ii 也能出现在级进低音的途中，过渡到 I 或 I 的第一转位。其位置由连线决定。作为属准备的整段路线可以写成 I–IV–ii–V–V7–I，增加 V 的七音后才做最后一次解决。

同一个 F 低音的两种属准备

F 与 A 稳住旋律，伴奏还有 C，形成 IV。B 上行到主音 C。

大调重属和弦

属三和弦、属七和弦或导和弦可以把调内另一个大、小三和弦暂时当成局部主和弦。减三和弦本身缺少稳定的主和弦音响，通常不作为这种目标。C 大调的 Dm 把 F 升成 F♯ 后成为 D，继续加 C 得到 D7。D 和 D7 是 G 的属与属七，也就是重属和弦 V/V 与 V7/V。

重属对 G 承担局部属功能，在全句里仍常置于下属与属之间。先定位后面的 G 或 G7，再核对之前的旋律能否容纳 F♯。旋律正以 F 自然音为重拍或长音时，可先保留 Dm，等 F 离开才升高。重属在句尾接 G 可以形成属区半终止，接终止四六则把强势的 G 低音提前。高潮上也可以独立用 D 或 D7 着色，让后续和声另择去向。

大调六级和弦

C 大调的 vi 是 Am。C、E 使它主要倾向主功能，A、C 又使它能接续 IV。vi 同时是关系小调的主和弦。它可以接在主、下属或属功能后。IV 到 vi 是上三度且有两个共同音，推进较弱。用于清楚分句时，可让后面再接 ii、重属或属。

属七后的完全收束和阻碍落点

低音 G 到 C，属七的 B 向上解决到 C，乐句落在主和弦。

大调三级和弦

iii 在 C 大调为 Em。B 是调的导音，令它带有属色彩。由于 E、G 与 I 共用，iii 又可以延伸主功能，接到 IV 或 ii。它与含 F 的 G7 有不同的趋向强度，结束乐句时，iii 通常只延伸过程，真正的收束留给 V7–I。

IV 后回到 I，句中已经清楚交代主功能。

大调完全功能体系中的转位和弦

转位改变的是实际低音，和弦根音保持原来的级数。正三和弦的转位可连接原位副和弦，副三和弦的转位也能填在正三和弦之间。选择低音时先看目标低音，再选包含中间音的和弦和转位，最后确认旋律的重音仍与和弦相容。

同一和弦序列的原位与下行低音

低音直接给出 C、G、A、E、F、C、G、C，各处和弦根音都清楚。

大调副七和弦

调内自然七和弦中，V7 是属七。其他各级三和弦加上调内七音，便有 Imaj7、ii7、iii7、IVmaj7、vi7、viiø7。新加入的七音会使音响更不稳定，原功能组基本保留。七音一般下行解决，根音上四度、下五度或上二度时，很容易为七音找到下一和弦音。

七和弦可以隔一个加入，保留三和弦作为落点，例如 I–iii–iii7–vi–vi7–ii–ii7–V–V7–I。也可将 iii7、vi7、ii 与终止四六组织到一句。连续自然七和弦的低音 C–F–B–E–A–D–G–C，适合把共同音与七音的级进织成同一条线。

转位七和弦之间的低音连接

C–Cmaj7/E–Fmaj7–C/G–Bm7(♭5)/D–C–G7–C 把 Imaj7 与 viiø7 都放在第一转位。转位使低音可按乐句需要独立设计，七音的去向仍由内声承担。

ii 与 ii7 的终止声部线

Dm 与 G7 共用 D、F，属七的三全音最后解向 C、E。
