级数说明和弦在调中的位置，排列和转位决定这些和弦怎样落在双手上。同一条连接可以保持大致走向，改变低音线，也可以在句末转向另一个和弦。

第 4 课 级数

音级与和弦级数

从主音起，音阶的七个音依顺序记作 Ⅰ 到 Ⅶ。C 大调的 Ⅰ 是 C，A 自然小调的 Ⅰ 是 A。在某级上，用音阶内的音每隔一音向上取三音、五音，就得到该级的调内三和弦。例如 C 大调的 Ⅱ 级是 D–F–A，写作 Ⅱm 或 ii。D 大三和弦中的 F♯ 超出 C 大调音阶，需要另行说明。

流行编曲可以混用自然、和声与旋律小调的材料。例如在 A 小调里用 Dm 作下属区域，再用 E 大三和弦的 G♯ 带向 Am。五声音阶分析有时借用同宫七声音阶作为编号参照。C 宫五声的 C、D、E、G、A 仍可写成 Ⅰ、Ⅱ、Ⅲ、Ⅴ、Ⅵ。若给这条五声旋律配 Dm，F 是七声和声参照里的音，仍可留在伴奏。

以当前主音或关系大调编号

以当前主音编号时，Am 在 A 小调里是 Ⅰm，C 是 Ⅲ。同一段若统一用关系大调 C 来编号，Am 写 Ⅵm，C 写 Ⅰ。在大小调交替的流行段落里，统一编号便于维持整段和弦位置的可比性。做功能分析时以当前主音编号，才能看清 E 在 A 小调里承担属功能。第 5 课的各组连接统一用 C 大调作参照。

七个级上的调内三和弦

左手逐级弹出 C 大调七个根音，右手配同一音阶内的三和弦。

主和弦、下属和弦与属和弦

Ⅰ、Ⅳ、Ⅴ 分别是主和弦、下属和弦、属和弦。主功能提供归宿，下属功能常把乐句引向属功能，属功能再向主收束。C 大调的 Dm 本身是Ⅱ级，位置上常和 F 一样起下属功能。Ⅲ、Ⅵ可能延展主功能，Ⅶ级减和弦可承担属功能。具体作用还取决于它连接了哪些和弦。

第 5 课 几种流行歌曲常用和弦连接

比较下面五组时，左手每小节给一枚低音，右手保持相近音区和相同时值。这样，属和弦后是回主和弦还是转向小和弦，以及低音是跳进、连级下行还是原地保持，都可以从同一大谱表中分辨出来。实际演奏可把同一顺序放进不同拍号，给各和弦分配不同长度。

常用连接的原型与变形

连接类型
安排

C–G–Am–Em–F–C–F–G。左手弹各和弦的根音，右手尽量用相邻键位接续。

同一低音与不同收尾

卡农式的两种下行变形都可以得到 C–B–A–G–F–E–D 的低音。B 低音上可以弹 G，也可以弹 Em。低音线一样，右手和弦的三音、五音和可保留的旋律音随之变化。较长的连接里，F–G/F 让 F2 留在左手，右手从 F 和弦换到 G 和弦。它把经过的和声变化放在不动的低音上。

同一段还可拼接原型与变形。例如卡农式前四个和弦照原型走，后四个和弦用 F–C/E–Dm–G。在四和弦循环的最后一小节，也可以在 C 之后用半小节 G/B 引回 Am。和弦的换拍、低音的顺序和旋律的停留音都能限制变形的选择。

循环接缝的两种和声节奏

共同的右手覆盖一次循环及下一轮首拍。加上 G/B 时，末小节的 C 缩为两拍。

两拍 C、两拍 G/B

Dm–G–C 和 F–G–C 都由 C 收束。将 C 换成 Am，属和弦的张力仍在，收尾却转向关系小调。Dm–Em–Am 与 Dm–E–Am 从 A 小调看分别是 iv–v–i 和 iv–V–i。第二种有 G♯ 向 A 上行半音，属到主的倾向更明确。
