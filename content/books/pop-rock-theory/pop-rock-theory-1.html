第 1 章 音阶的排列与音的走向

C 大调在钢琴上可以只用白键，在吉他上却要跨品、换弦。同一条音阶到了 D 大调还会出现两个升号。把位置换成音与音之间的距离，就能用同一套办法找音、移指型，再把零散的音接成一条低音线。

半音、全音与两组四音

钢琴上，两黑键组左边的白键是 C。由 C 开始顺弹白键，得到 C、D、E、F、G、A、B，再到高一个八度的 C。八度内有七种白键音和五种黑键音，高处的 C 重复了起点的音名。固定唱名里的 Do、Re、Mi、Fa、Sol、La、Si 分别对应 C、D、E、F、G、A、B。

两个紧邻的琴键相隔半音，计入黑键。C 和 D 之间隔着一个黑键，所以是两个半音，也就是全音。E–F 和 B–C 中间没有黑键，相隔半音。把音阶分成 C–D–E–F 与 G–A–B–C，就能看到两组的内部距离相同。

从 D 排白键时，D–E 是全音，但 E–F 只有半音。把 F 提高为 F♯，E–F♯ 和 F♯–G 就分别成为全音、半音。上方四音同理，把 C 升为 C♯。两条大调音阶的键位和音高不同，相邻音距相同。

主音

一品一个半音

吉他、贝斯和尤克里里沿同一条弦向高品移动一格，音高上升半音。空弦记为第 0 品，第 1 品是靠近弦枕的第一格。两组大调四音都从组首数第 0、2、4、5 个半音，因此能用相同的品距来弹。换弦时起点由空弦音决定。标准四弦贝斯的 E、A、D、G 四根弦与标准吉他的四根低音弦一一对应，同品位的音名相同，贝斯实际低一个八度。

同一四音结构在三种指板上的位置

吉他在第 5 弦第 3 品和第 4 弦第 5 品分别起奏 C 和 G。

同一个实际音高也可在一件乐器上有多个位置。标准吉他的第 5 弦第 5 品和第 4 弦空弦都是 D3，二者之间是同度。第 5 弦第 3 品 C3 到第 2 弦第 1 品 C4 则隔了八度。

升降号与等音

升号 ♯ 使音高升半音，降号 ♭ 使音高降半音。在十二平均律的钢琴和吉他上，F♯ 与 G♭ 是同一键或同一弦上的同一品位。F♯ 以 F 为基准，G♭ 以 G 为基准，写法反映音在音阶或和弦中的身份。白键也能用升降号来写，例如 E♯ 与 F 等音。

音级与指型的平移

音名说明具体是哪一个音，音级说明它在调里的位置。D 在 C 大调是第 2 级，到了 D 大调就是第 1 级。第 3 级从主音数到第三个字母，C 大调是 E，D 大调是 F♯。两者距各自的主音都是四个半音。

把吉他上一套没有空弦的指型整体右移两品，每一个音同时升高全音。C 大调第 1 级在第 5 弦第 3 品，D 大调第 1 级在同弦第 5 品。键盘上的 C 与 D 大调虽然保持相同音距，黑白键的分布让手的形状随之改变。

同一指型横移两品

从 C 大调换到 D 大调，每个音保留弦号并提高两品。

和弦符号里的数字从和弦根音计算。以 C 大调中的 Dm 为例，F 是全调的第 4 级，却是 Dm 的三音，因为从 D 数到 F 要经过 D、E、F。看到 D6 时，计算的起点仍是 D，六音是 B，即使这个和弦出现在别的调。常见符号的具体拼法在第 3 章展开。

音级与数字和弦谱
  • 罗马数字通常用来标记和弦根音在调内的级数。C 大调的 Dm 在第 2 级，可写作 ii。
  • 纳什维尔数字系统用阿拉伯数字写和弦的调内位置。在 C 大调把 C–F–G 写成 1–4–5，移到 D 大调就对应 D–G–A。记录小和弦等性质时须另加符号。

级进、半音与四五度运动

旋律沿音阶相邻音走叫级进。C 到 G 可用 C–D–E–F–G 连起来；相邻调内音之间也可以再插入半音。跳进则拉开两个起音之间的距离，可交代根音或突出轮廓。

按纯五度上行会得到 C–G–D–A–E–B–F♯。从 C 向上数七个半音是 G，向下数五个半音也到 G。前者是上行纯五度，后者是下行纯四度，两个 G 相差八度，可以按音域和指法选用。反向回到 C 则可下行纯五度或上行纯四度。在 C 大调中，G7 的 B 和 F 分别趋向 C 和 E，这时根音 G→C 带有属回主的作用。

标准吉他或贝斯的相邻低音弦相隔纯四度。在这个范围里，同品转到低一根弦，就向下走五个半音。转向高一根弦再加两品，就向上走七个半音。吉他的第 3 弦和第 2 弦相差大三度，跨过这两弦要按调弦重新计算。高 G 调弦的尤克里里从第 3 弦空弦 C4 转到第 4 弦空弦 G4，实际是上行纯五度。

音高、音名、音程与音域

定位单音与音的关系
术语含义例子
音高声音的高低。调音使同一音高的声音对齐。C4 比 C3 高一个八度。
音名用字母与升降号标记音。C3 和 C4 都叫 C，数字区分所在八度。
音程两个音之间的距离，由字母级数与半音数共同决定。C–E 跨三个字母且相差四个半音，是大三度。C–E♭ 相差三个半音，是小三度。
音阶选定的音按高低次序排成的音列。自然大调有七个不同音，五声音阶有五个。
调音乐围绕某个主音组织起来的关系，调名还要说明调式。C 大调的主音是 C，A 小调的主音是 A。
音域声部、乐器或乐句的最低音到最高音。一段旋律最低 D4，最高 B4，音域就是 D4–B4。
