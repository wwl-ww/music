第四章 和弦进行与低音线条

吉他手按 G，贝斯手弹 B，合起来仍有 G 和弦的构成，但低音已经变了。认识了和弦的拼法以后，本章把三个问题分开。和弦在乐句里做什么，根音如何连接，真正听到的最低音又如何走向下一拍。

主、下属与属功能

C–G7–C 已经有出发和归来的轮廓。C 确立主音，G7 的 B 上行半音到 C，F 下行半音到 E，形成清楚的回归。加入 F 就有了 C–F–G7–C。F 先把乐句带离主和弦，并准备随后的属和弦。在 C 大调中，I、IV、V 是代表这三种功能的主要三和弦。

C 大调的常见功能与共享音

下属 S · 离开主和弦或准备属和弦IV、ii

功能取决于上下文。Am 若接在 C 后、继续走向 Dm–G7–C，可延续主功能。Am 若紧跟 G7 出现在预期回 C 的句尾，则是另一种走向。Em 与 C 共享音，但低音 E 和它在句中的位置会影响听感。类似地，保留和弦里的共同音有助于衔接，旋律的长音仍需要与替换后的和弦核对。

把 F 换成 Dm7，可以保留 F、A、C，低音由 F 改为 D。于是 F–G7 的根音上行二度改成 Dm7–G7 的下行五度或上行四度。属前与属的功能顺序相同，后一种形成常见的 ii–V，接 C 即 ii–V–I。

同一句尾的功能骨架与替代

C–F–G7–C。属七中的 B–F 分别去往 C–E。

五度链与副属和弦

在 C–Dm–G7–C 之间加入 Am，A–D–G–C 连续三次出现根音下行五度关系。再把 Em 接在 Am 前面，得到 E–A–D–G–C。这样的链条可以包含调内小和弦。五度关系说明两个根音的距离，属七功能还要看三音、七音与目标和弦的关系。

例如把 Em7 的 G 升为 G♯，得到 E7。G♯ 到 Am 的根音 A 只差半音，D 同时可下行到 C。若乐句依然以 C 为中心，E7 就是指向 vi 的副属和弦。连续使用 B7、E7、A7、D7 能分别强调 Em、Am、Dm、G。只强调其中一两个目标，可以保留更多自然音阶内的连续性。

连续五度与副属和弦

Bm7(♭5)–Em7–Am7–Dm7–G7–C。根音沿下行五度关系推进，全句使用 C 大调的音。

局部强调与转调的判断

一个副属到达目标和弦，可以短暂把它当作归宿来听。若后面仍回到原调的属与主，原调通常继续成立。转调须有足够的乐句或终止来建立新中心，不能只靠一个调外音判断。

转位、斜线和弦与低音连线

同为 C 和弦，若最低的是 C，为原位。低音换成 E 或 G，分别是第一转位 C/E 和第二转位 C/G。 只调整上方声部的先后与八度，整组声音的最低音仍是 C，属于给原位和弦换一种声部配置。合奏时，应以整个乐队的实际最低音判断转位。

斜线左边写和弦，右边写指定的低音，G/B 也可写 G on B。右侧若是和弦音，可以构成转位；若是和弦外低音，写法仍然成立，例如 C/D 是 C 三和弦放在 D 低音上。

标准调弦吉他的高音三弦上，下面三种手型都包含 C、E、G。若贝斯手另弹更低的 C，则乐队实际仍在 C 和弦原位。

C–G–Am–G–F 原本让几个低音随根音跳进。第二个和弦取 G/B 后，贝斯得到 C–B–A。到第四个位置，可保留贝斯的 G，把上方 G 和弦换成 Am，形成 Am/G。若伴奏还含 G，可标成 Am7/G。两者合奏都包含 A–C–E–G，各声部的音区和重叠则由编配决定。

同一上方和弦与不同低音

低声部与和弦根音一致。第二个低音是 G。

和弦符号通常标出要在合奏中维持的低音。贝斯在和弦拍内短暂经过某个音时，可以把音写在贝斯声部，不必给每个经过音另标一个和弦。

经过减七和弦

从 F 走到 G7 时，低音可以插入 F♯。若上方同时奏出 F7 的 A、C、E♭，四个合奏音为 F♯–A–C–E♭，正是 F♯dim7。少了 E♭，只剩 F♯–A–C，则是 F♯dim。这个写法让低音 F–F♯–G 连续以半音上行，上方音也有清楚的去向，例如 E♭ 可下行到 G7 的五音 D。

升 F 低音与经过减七

F 直接走到 G7。F 的低音维持到小节末。

三全音替代与半音下行

G7 的三音 B 与七音 F 相距三个全音。D♭7 的三音 F 与七音 C♭ 共享这对音高，B 与 C♭ 在十二平均律中等音。两和弦的根音也相距三全音，可以用 D♭7 替代 G7，让 Dm7–G7–C 的五度链变为 Dm7–D♭7–C，取得 D–D♭–C 的半音低音，同时保留两条内声部的解决。

这条规则也可用于副属。A7 指向 Dm，它的替代是 E♭7。两处都替换后，Em–E♭7–Dm7–D♭7–C 的低音依次为 E–E♭–D–D♭–C。若旋律原本停在被换掉的音上，还要检查新和弦中这个音的身份。

属七与三全音替代

Dm7–G7–C，低音按五度关系前进，B 和 F 分别解决到 C 和 E。

吉他低音弦上的三全音位置

标准调弦第六、第五弦空弦相差纯四度（五个半音）。从第六弦切到第五弦再上移一品，共升六个半音。例子是第六弦第 3 品 G 与第五弦第 4 品 D♭。反向移动是同一组音，或者可在一根弦上移动六品。

同主音小调借用与句尾

C 大调常以 F–G7–C 收句。若把 G7 改成同主音 C 小调的 Fm，就得到 F–Fm–C。F 的三音 A 降成 Fm 的 A♭，再到 C 和弦的 G，形成 A–A♭–G 的半音线。Fm 是借来的小下属和弦，这段的终点仍是 C 大和弦。

换成 A♭ 大三和弦，也能保留 A–A♭–G。Fm 含 F–A♭–C，A♭ 含 A♭–C–E♭，替换让第二个和弦低音从 F 移到 A♭。C 小调中的 Ddim（D–F–A♭）也可借用，若叠加 C，则写 Dm7(♭5)。这些写法都能在 C 小调音阶里找到，和临时用 E7 引向 Am 的副属做法有不同的声部走向。

同一句尾的属七与借用和弦

F–G7–C，最后由属七回主。最高音走 A–G–G。

为同一条旋律重配和声

重配和声是保留可以辨认的曲调，改变其伴奏和弦或和声落点。先确认长音怎样落在和弦上，再区分句尾归宿与途中可换的部分，最后让贝斯在关键点落到明确的音。弱位置可以用级进低音连接，只有当每拍都形成有规律的行进时，才接近常说的行进低音（walking bass）织体。

示范中第二小节原来用 F 伴奏，旋律的 A 和 F 都能保留在 Am–F 的新配法里。第三小节的 F 换成 Dm7 后，F 仍是和弦音，但多了 D–G–C 的五度链。两版都回到 C，改动可以从旋律、和弦与低音三层同时核对。

同一旋律的两种和声组织

基础配法只用 C、F、G7。第一和第三小节分别从 C 和 F 开始。

按层整理听到的进行

先写谱上能确定的低音，再由伴奏与旋律推断根音和和弦性质。最后把和弦放回全句，确认中途的局部趋向和真正的归宿。写作时也可以沿这个顺序从骨架推到具体音符。
