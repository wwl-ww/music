第四章 和弦进行与低音线条

吉他手按 G，贝斯手弹 B，合起来仍有 G 和弦的构成，但低音已经变了。认识了和弦的拼法以后，本章把三个问题分开。和弦在乐句里做什么，根音如何连接，真正听到的最低音又如何走向下一拍。

主、下属与属功能

C–G7–C 已经有出发和归来的轮廓。C 确立主音，G7 的 B 上行半音到 C，F 下行半音到 E，形成清楚的回归。加入 F 就有了 C–F–G7–C。F 先把乐句带离主和弦，并准备随后的属和弦。在 C 大调中，I、IV、V 是代表这三种功能的主要三和弦。

功能替代和弦的共同音

把两个和弦的构成音对齐，可以找出替换时能保留的声部。低音、旋律长音和下一和弦的去向，决定这次替换在乐句中是否合适。

  • 主功能 I 与 vi。 C 是 C–E–G，Am 是 A–C–E，两者共享 C、E。给 Am 加上七音 G 成为 Am7，C–E–G 就能全部保留在上方，贝斯由 C 改奏 A。
  • 主功能 I 与 iii。 C 与 Em（E–G–B）共享 E、G。若原来用 Cmaj7，两个和弦还共享 B。Cmaj7 可以用 C 作低音，在上方配置 E、G、B。换成 Em 时，上方三音可以原样保留，低音改为 E。
  • 下属功能 IV 与 ii。 F（F–A–C）与 Dm（D–F–A）共享 F、A。Dm 加上 C 成为 Dm7 后，保留了 F 三和弦的全部音。接 G7 时，原来的 F→G 改为 D→G，根音由二度连接变成四五度连接。
  • 属功能 V 与 vii°。 G7（G–B–D–F）去掉根音 G，留下的 B–D–F 正是 Bdim。两者都可保留 B→C、F→E 的解决。Bdim 再加 A 是 Bm7(♭5)，它相当于 G9 去根音后的四个音。

功能要看前后。C–Am–Dm–G7–C 中，Am 在属前和弦 Dm 到来之前延续主功能。G7–Am 出现在原本预期回 C 的句尾时，低音落到 A，形成阻碍进行。两处都出现 Am，差别在它承接了哪个和弦、乐句接下来怎样收束。

同一句尾的功能骨架与替代

C–F–G7–C。属七中的 B–F 分别去往 C–E。

五度链与副属和弦

在 C–Dm–G7–C 之间加入 Am，A–D–G–C 连续三次出现根音下行五度关系。再把 Em 接在 Am 前面，得到 E–A–D–G–C。这样的链条可以包含调内小和弦。五度关系说明两个根音的距离，属七功能还要看三音、七音与目标和弦的关系。

例如把 Em7 的 G 升为 G♯，得到 E7。G♯ 到 Am 的根音 A 只差半音，D 同时可下行到 C。若乐句依然以 C 为中心，E7 就是指向 vi 的副属和弦。B7、E7、A7、D7 分别可引向 Em、Am、Dm、G。若它们连成 B7–E7–A7–D7–G7，各个和弦也可成为下一个属七的到达点，直到 G7 接回 C。

连续五度与副属和弦

Bm7(♭5)–Em7–Am7–Dm7–G7–C。根音沿下行五度关系推进，全句使用 C 大调的音。

局部强调与转调的判断

一个副属到达目标和弦，可以短暂把它当作归宿来听。若后面仍回到原调的属与主，原调通常继续成立。转调须有足够的乐句或终止来建立新中心，不能只靠一个调外音判断。

转位、斜线和弦与低音连线

同为 C 和弦，若最低的是 C，为原位。低音换成 E 或 G，分别是第一转位 C/E 和第二转位 C/G。 只调整上方声部的先后与八度，整组声音的最低音仍是 C，属于给原位和弦换一种声部配置。合奏时，应以整个乐队的实际最低音判断转位。

斜线左边写和弦，右边写指定的低音，G/B 也可写 G on B。右侧若是和弦音，可以构成转位；若是和弦外低音，写法仍然成立，例如 C/D 是 C 三和弦放在 D 低音上。

标准调弦吉他的高音三弦上，下面三种手型都包含 C、E、G。若贝斯手另弹更低的 C，则乐队实际仍在 C 和弦原位。

在 C–G–Am–G–F 里，贝斯可以按根音跳进，也可以把几个位置连成逐级下行。表里分别写出和弦名称和实际低音。

低音与上方和弦的两次改写

低声部与和弦根音一致。第二个低音是 G。

从「根音低音」到「低音改用转位」，第二处只改最低音 G→B。再换到「同一低音再配和声」，第四处低音仍是 G，上层改用 Am。Am/G 合奏后已包含 A–C–E–G。如果伴奏把 G 也当作上层和弦的一部分，谱上还可能写作 Am7/G。

和弦符号通常标出要在合奏中维持的低音。贝斯在和弦拍内短暂经过某个音时，可以把音写在贝斯声部，不必给每个经过音另标一个和弦。

经过减七和弦

从 F 走向 G7 时，可先让上方出现 F7 的 A、C、E♭。把 F 交给贝斯移成 F♯，就得到 F♯dim7。若上方只奏 A、C，则构成 F♯dim。

升 F 低音与经过减七

F 直接走到 G7。F 的低音维持到小节末。

三全音替代与半音下行

G7 的 B 与 F 构成三全音。D♭7 的 C♭ 和 B 等音，所以替换后仍可保留这两条解决线。G 与 D♭ 两个根音也相距三全音。

这条规则也可用于副属。A7 指向 Dm，它的替代是 E♭7。两处都替换后，Em–E♭7–Dm7–D♭7–C 的低音依次为 E–E♭–D–D♭–C。若旋律原本停在被换掉的音上，还要检查新和弦中这个音的身份。

属七与三全音替代

Dm7–G7–C，低音按五度关系前进，B 和 F 分别解决到 C 和 E。

吉他低音弦上的三全音位置

标准调弦第六、第五弦空弦相差纯四度（五个半音）。从第六弦切到第五弦再上移一品，共升六个半音。例子是第六弦第 3 品 G 与第五弦第 4 品 D♭。反向移动是同一组音，或者可在一根弦上移动六品。

同主音小调借用与句尾

C 大调常以 F–G7–C 收句。把中间的 G7 换成从 C 小调借来的 Fm，也能在同一位置回到 C 大三和弦。最容易辨认的是伴奏里那条半音线。

换成 A♭ 大三和弦，也能保留 A–A♭–G。Fm 含 F–A♭–C，A♭ 含 A♭–C–E♭，替换让第二个和弦低音从 F 移到 A♭。C 自然小调与 E♭ 大调共用音集，因此也可从 E♭ 大调的调内和弦中核对这些音。Ddim（D–F–A♭）亦可借用，叠加 C 后写成 Dm7(♭5)。它可接 G7，或使 F、A♭ 下行至 E、G，直接解决到 C。

同一句尾的属七与借用和弦

F–G7–C，最后由属七回主。最高音走 A–G–G。

为同一条旋律重配和声

重配和声是保留可以辨认的曲调，改变其伴奏和弦或和声落点。先确认长音怎样落在和弦上，再区分句尾归宿与途中可换的部分，最后让贝斯在关键点落到明确的音。弱位置可以用级进低音连接，只有当每拍都形成有规律的行进时，才接近常说的行进低音（walking bass）织体。

示范中第二小节原来用 F 伴奏，旋律的 A 和 F 都能保留在 Am–F 的新配法里。第三小节的 F 换成 Dm7 后，F 仍是和弦音，但多了 D–G–C 的五度链。两版都回到 C，改动可以从旋律、和弦与低音三层同时核对。

同一旋律的两种和声组织

基础配法只用 C、F、G7。第一和第三小节分别从 C 和 F 开始。

按层整理听到的进行

先写谱上能确定的低音，再由伴奏与旋律推断根音和和弦性质。最后把和弦放回全句，确认中途的局部趋向和真正的归宿。写作时也可以沿这个顺序从骨架推到具体音符。
