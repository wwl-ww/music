第五章 五声、蓝调与其他音阶

即兴旋律需要在几个容易辨认的音上落稳，同时给经过、转折和重复留下余地。五声音阶提供一个小音集。用同一组音换主音、换伴奏，再补入蓝调音，就能分辨音集、调性中心和当下和弦分别带来的听感。

大调与小调五声音阶

C 大三和弦给出最稳的三个音 C、E、G。加上二级 D 与六级 A，得到常用于流行、摇滚和民谣的大调五声音阶。它也可以由自然大调略去四级 F 和七级 B 得到。恢复 F、B 后，E–F 与 B–C 两个半音又出现，可以分别向邻音或和弦目标运动。

同一组音围绕 A 组织，得到关系小调的小调五声音阶。A 小调的根音、三音、五音是 A、C、E，常用的补充音是 D、G。它们分别是 A 的四级和降七级。记号 ♭3、♭7 表示比同主音大调的三级和七级低半音。同是 C 起头时，C 小调五声音阶改用 C、E♭、F、G、B♭，和 C 大调五声音阶并非同一音集。

音集相同，主音可以不同。 C 大调五声和 A 小调五声包含同样的五个音。低音、乐句的长音与收束位置决定这些音围绕哪个中心组织。

同一音集的 C 与 A 两种归宿

两版共用第一小节的题头。C 版的低音落到 C，末音也在 C 上延长。

五声音阶盒型与找调

标准定弦吉他的同一根弦每升一品就是升半音。在第五到第八品用按弦音构成的盒型，既可围绕 C 弹大调五声音阶，也可围绕 A 弹小调五声音阶。所有点沿同一组弦向高音平移两品，音级结构保留，主音分别移到 D 和 B。有空弦的指型要先把空弦换成可以随手型一起移动的位置，或用变调夹整体改变空弦音高。

高音两弦的音集线索

听音记谱时，可以先在第 1、2 弦找到一组相隔三品的两对音。两弦的第 7、10 品给出 B–D 和 F♯–A。这四个音同时出现在 G、D、A 三个自然大调中。再确认两个半音邻点，就能缩小候选范围，最后由句尾长音或终止和弦判断主音。

伴奏和弦与五声旋律的落点

长音、强拍音和句尾音较容易被听成和弦的骨架。短音可以连接骨架，也可以在和弦上停留，形成可辨认的色彩。对 C 大调五声音阶而言，C、E、G 在 C 和弦上都能站稳。换到 Am，A、C、E 成为直接的落点，原有的 G 可以作为小七度色彩。

五种和弦语境中的旋律用音

C 和弦上的 D 与 A 都用来连向和弦音，旋律最终落到 C。

蓝调音与经过性的降五级

在 A7 的伴奏上，旋律既可以顺着和弦的大三音 C♯，也可以使用 A 小调五声里的 C。旋律的 ♭3 和伴奏的 3 在这个语境里形成有意保留的张力。G 是主音 A 上方的 ♭7，与 A7 的七音相同。再在 D 与 E 之间加入 E♭（♭5），得到常用的小调蓝调音阶。这个音常以较短时值连接四级和五级，拉长它则会突出半音张力。

蓝调的音高表现还包括吉他推弦、滑音和人声微调。固定音高的键盘或五线谱可以先标出 ♭3、♭5、♭7 的位置。演唱与拨弦时，三度可以在 C 与 C♯ 之间形成更细的变化。

同一 A7 伴奏上的三度与降五级

旋律用 C♯ 与 A7 的三音重合。这个音把旋律同伴奏的大三度连在一起。

减七与增三和弦的等距结构

和弦结构可为即兴提供临时的落音。减七和弦把十二个半音分成四份，增三和弦分成三份。以 D♯dim7 为例，D♯–F♯–A–C 每隔三个半音。换其中一个音作为最低音，听到的音高类保持相同，音区、拼写和解决方向仍可不同。增三和弦 Caug 的 C–E–G♯ 每隔四个半音，同理。

D–D♯dim7–Em 的低音 D–D♯–E 是连续的半音。D♯ 同时是 E 的导音，D♯dim7 也恰好是 B7(♭9) 去根音后的四个音。另一种写法在 C–Caug–C6 中保持低音 C 和内声 E，用上声部 G–G♯–A 表示变化。两种写法都能用指定声部的半音运动把和弦接起来。

低音中的减七与上声部的增三

D 与 Em 直接相接，低音跨一个全音。

等音音集与和弦谱简写
  • 十二平均律下，减七只有三种不同的音高类集合，可用 Cdim7、C♯dim7、Ddim7 分别代表。每种集合中有四个等距的音，对应四个可能的根音。增三有四种集合，可用 Caug、C♯aug、Daug、D♯aug 代表。
  • 同一减七或增三按弦指型整体平移三个或四个品位，分别得到同一类音集的另一种排列。实际伴奏仍要保留指定低音，以及负责解决的声部。
  • 有些流行谱把减七缩写成 dim。单独看到 dim 时，默认先读作减三和弦，再结合录音、谱例或段落功能判断有没有减七度音。

调式、小调变体与外音

同样的七个音在不同主音上排列，半音落点随之改变。C 大调的白键音如果持续围绕 D，在 D 根音与 Dm 和弦上把 B 放到显眼的位置，会形成 D 多利亚调式的色彩。以 D 自然小调的 B♭ 对照，区别集中在六级。调式听感取决于伴奏和旋律共同建立的中心，仅从 D 开始经过一次白键音仍可能听成 C 大调。

同一 D 小和弦上的自然小调与多利亚

伴奏持续用 Dm。旋律在 B♭–A 的半音上形成自然小调的六级色彩。

三种小音阶、调外演奏与自由爵士
  • A 自然小调是 A、B、C、D、E、F、G；A 和声小调把 G 升为 G♯，可形成 E7 的大三音并解决到 A。A 旋律小调上行常把 F、G 同时升为 F♯、G♯，减小六级到导音的跨度。传统下行通常还原，爵士中上下行常保留升六级与升七级。
  • 调外演奏（playing outside）可以把熟悉的五声音型短暂整体移高半音，再把末尾移回原调的和弦音。伴奏继续维持原中心，听感来自音型暂时离开与回到这个中心之间的距离。
  • 自由爵士的一些演奏可以不按预先定好的和弦序列或固定拍节发展，在互动中依靠动机、音色、力度和彼此的呼应组织音乐。
