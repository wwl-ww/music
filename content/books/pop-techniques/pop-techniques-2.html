第2章 编曲

《留一盏灯》的副歌已经有了能记住的旋律。段落铺陈试听用同一条旋律比较鼓和贝斯何时加入、键盘怎样留出空间，以及副歌第一句怎样从前一段接出来。

工程模板与音量余量

DAW（数字音频工作站）的模板可以预存音轨、软件乐器、发送效果和输入输出。作曲模板只需导唱旋律、钢琴、节奏组与贝斯，便于随手记下句子。编曲模板可再备齐按乐种常用的合奏音色、混响与延迟发送，以及人声、吉他等录音输入。合成器直录和经过硬件压缩器有不同输入路径时，可以分别存预设。耳机与音箱用不同监听路径时，也可以预设输出，方便核对。

经常边写旋律边编曲时，可以让常用的乐器随同一模板加载，把不常用的预设按制作类型存好。几个声部需要处在同一空间时，各轨可以同时把一部分信号送进同一个混响，保留各自的干声，也能分别决定送入多少。

多条轨道的声音相加，单轨都没亮红灯，总线仍可能超出允许的峰值。编曲开始时可以把各音轨推子从标称 0 dB 下拉约 10–15 dB，给叠加留余量，再按相对比例平衡。这个数是起点。轨道推子的 0 dB 表示增益不变，而数字电平表的 0 dBFS 是满刻度。监听声音偏小可调耳机或音箱的音量，工程电平仍以表头为准。

响度最大化器主要用于混音或母带的后续处理。编曲早期把总线压得又响又平，可能会把瞬态、弱音与停顿的差异盖过去，也容易误判单轨的比例。调响度之前保留动态；遇到总线过载，沿信号路径检查轨道、插件输入和总线，并降低实际过载处之前的电平。

录音、工程与输出的削波排查
  • 录音已经削波时，拉低回放推子只会让失真变小声。可以单独试听可疑轨道，并从录音输入重新检查。
  • 浮点混音总线的电平一时超过 0 dBFS，内部仍可能保留峰值。部分插件的输入、硬件输出或定点文件导出仍会削波。应检查整条信号路径的余量。
  • 已将最大化器用于估计成品听感时，可以暂时旁通并对齐监听响度，再核对重音、尾音与各轨比例。

段落铺陈与副歌的落点

副歌的第一句沿用第1章的四音记忆点。它前面有段落变化时，副歌的到来更容易听辨。前奏交代音色和节拍，主歌 A 留空间给歌词，主歌 B 引入一项可辨认的变化。进入副歌前，既可以加密节奏，也可以暂时收住伴奏。副歌结束后，可以回到前奏动机，再在尾奏里保留一句副歌材料。

四小节共用同一旋律与和声，每小节示意一个段落的配器状态。

变化放在有辨识度的地方，才会在导唱进入后依然可闻。初稿可把差别做大，例如过渡段先撤去整个律动组，副歌一起恢复，再按歌曲的尺度收回来。把两版以相近响度连着比较，有助于分辨是段落设计更清楚，还是整段仅仅变响了。

前景、背景与声部层次

一条连续的乐句在合奏中容易被听成独立的线。主唱已经是一条线，键盘、吉他与音序器再各唱一条，常会争同一个位置。把其中一条改成句间的一个短音或和弦重击，就能保留它的颜色，同时把句子的走向还给主唱。

对照可调整的地方
点与线前景保留连贯的句子，背景可改成间隔较远的单个起音。
高与低为高、中、低各安排用途，挪开与主唱反复重合的声部。
明与暗较暗的背景可以显出明亮的旋律音色，也可以反过来使用。
浓与淡起音轮廓清楚的声部容易来到前景，柔和的延音可提供背景和声。
强与弱有轻重差别才有重音。MIDI 力度在许多采样乐器上还会改变起音和音色。
左与右分开有冲突的声部，也让左右总体保持平衡。单声道核对能发现仍然存在的遮蔽。
缓与急细分、起音密度和段落收放可以改变推进感，速度仍可保持不变。

声部过多时，先查功能重叠。同时刷和弦的几把乐器、同一中音区的几层长音、与主唱旋律一起移动的琶音，都会使重点难辨。可以暂时静音一条轨，再找出被它遮住的词和旋律。若两条轨确实要合成一个音色，可以让一条提供短起音，另一条提供延音，再在合奏里核对。和弦伴奏通常可从一两种乐器起步。

编曲工程的轨道数与声部数

一首含约 30–40 条器乐轨的编曲工程，可以有 3–6 条吉他轨、1–3 条键盘轨、3–6 条合成器轨与几条效果声轨。摇滚实鼓录音时，大鼓、小鼓、嗵鼓、镲片、吊麦与室内麦可以各占轨道。它们合起来仍是一个鼓组。电子舞曲可从鼓件与循环乐句构成的基础律动起步，再加贝斯、和弦与音序器。导唱叠录、大编制弦乐与管乐也会增加轨数。轨数随配器和录音方式而变化。

和弦声位与省略音

密集排列把上方和弦音聚在一个较小的音域。开放排列把其中一些音移到别的八度，形成更宽的间距。两种写法可以保留同样的最低音，所以能够在同一种转位内变化。两个和弦声部同时出现时，可以让钢琴给出紧凑的击点，再用合成器长音填充不同音区。若两者需要合成一个音色，也可以刻意重叠。

贝斯已经奏 C 时，其他乐器还可留下三音 E 与大七度 B，省略没有承担旋律任务的纯五度 G。遇到减五度、增五度，或五音正好是最低音或上方旋律时，这个音就有需要保留的任务。

Cmaj7 的三种声位

密集声位的上方四个和弦音集中在一个八度内。

音色选择与均衡

大鼓缺少结实的起音、钟铃缺少轮廓时，可以先从同类素材中找更合适的替代，再用同一句伴奏比较。效果器能挪动已有声音的重点，源音色能在合奏里承担什么仍取决于本身的起音与延音。比较不同软件合成器预设时，可以固定音高、力度和短句，分别改变振荡器波形、滤波、放键后的衰减时间或叠层音量。常用音色和有效改动可以按用途保存。

调整对象判断方法
音色延音听起来舒服，也要判断起音轮廓是否承担得起声部的任务。
均衡（EQ）高通削弱截止频率以下的成分，低通削弱以上的成分，也可只调整较窄的频段。截止频率取决于音高、素材与声部职责。
力度改变 MIDI 起音力度可能触发不同采样或改变滤波。先独奏辨认从软到硬的变化，再放回合奏选合适的演奏力度。
音量推子改变已产生的声音的电平。声部快要被盖住或略微抢前时，微调后以相近的监听响度比较。
音高带可辨音高的效果音要放回调性与局部和弦中核对，必要时换八度、移调或改素材。

手册的 EQ 曲线只给排查方向。两种贝斯、大鼓或经过失真的素材，即使名称相同，能量分布也会不同。分别观察起音和尾声的频谱，可以了解这些部分集中在哪些频段。在全曲里找到被遮住的部分，再确定该减少哪一个声部的频段。可以暂时扫频找出问题区，但最终保留多少取决于合奏中的听感。同一个大鼓，在一首歌里可以保留低频厚度，在另一首歌里可以留下更多中频起音。

底鼓、贝斯与低频分工

低频听起来空有两种常见成因。素材本身缺少稳定的低频或清楚的起音，或者底鼓、贝斯、次低音和合成器在同一低区重叠，把彼此的轮廓遮住。可以只播放底鼓和贝斯，检查哪一条负责持续的低频，哪一条负责击点。如果低频主体交给贝斯，就挑一个起音清楚、尾巴较短的底鼓。逐步加回其他声部时，留意是哪一轨盖住了低音的起伏，并检查是要减音、移音区、换素材还是削减多余的低频。

选鼓声也要分开判断起音、厚度与音高。短而集中的大鼓适合清楚交代速度，音体较宽的打击可用在较慢、想保留重量的律动里。下调采样的音高能增加重量，调得太低时，起音可能变钝、尾巴挤进下一拍。小鼓的音高有时很明显，过高会让起音突出却失去与大鼓的联系，过于厚重又可能挤住低端。实际选择取决于鼓组在乐段里承担推进、重量还是纹理。

弦乐编制与声部定位

弦乐先决定规模与职责。小提琴一、小提琴二、中提琴与大提琴可以组成四重奏，一人一部。双四重奏可以每部两人，弦乐合奏还可以用 8–6–4–4 或 6–4–2–2 等编制，数字依次是四个声部的人数。低音提琴可另设一部。采样软件里标明人数的预设会带来不同的厚度。把整套大型弦乐的全编制音色齐奏在每一条轨上，会轻易超过原来想要的分量。

同度齐奏突出一条线，分部和声形成背景，独立副旋律可在换气或器乐段接句。短而有节奏感的片段穿插在延音中，可以交代段落推进。左右定位常由小提琴偏左，向中提琴与大提琴一侧逐渐展开，低音声部是否偏右取决于编制和录音布局。流行编曲可随其他乐器的分布调整，人声居中时，弦乐背景可以适当收窄。

齐奏落点、停拍与鼓组细节

齐奏点要配合共同的起音与收尾。所有乐器可以一起强调重拍，也可以只让旋律和和弦声部打出一个共同重音，鼓组沿用原节奏。这里把主歌末尾简写成一小节，再接「留一盏灯」的副歌入口。谱面显示主旋律和键盘，试听还包括贝斯和鼓组。

进入下一段前的合奏停拍

两小节之间不停拍时，鼓与贝斯的律动连续通过段落交界。

整组停拍时，鼓、低音、循环素材与和弦的结束时间都需要对齐。失真吉他的拖尾、循环素材内的底噪和效果发送里的混响，可能仍会穿过切口。若要保留一条滤过高频的循环节奏或效果声，其他声部一起停下时，它会更容易被听见。这类变化留在几个主要转段处，停与再起的对比更突出。

编写仿真鼓组时，从真实演奏和鼓采样库的 MIDI 节奏型中分辨鼓件、力度、滚奏和过门。常见限制是双手和双脚的分工，例如鼓手同一刻可以用脚踩大鼓、用两只手击小鼓与踩镲。若还要加入嗵鼓，便需要改动手上的击打安排。小鼓的幽灵音是力度很轻的击打，通常落在主重音之间，衔接空隙。保留重拍、弱音与少量时差，比给每个音随机偏移更能保住律动。

效果素材与音频编辑

MIDI 适合继续修改音高、时值和演奏方式。保留原轨并渲染出一条音频后，可以直接看到起音与空白，把局部切开、反转、时间伸缩或追加调制效果。停用已渲染的虚拟乐器轨能够减少实时负荷。素材库可按反向音、扫频、撞击等作用归类，选取时回到歌曲里检查切点、次数、音高与音量。两次撞击的间隔很近，或相同效果每段都出现时，预告段落变化的效果会减弱。

编辑位置与结果
切片片段边缘贴住拍点时，前置空白仍可能让真正的起音偏后。放大波形确认起音和尾巴，在剪辑交界加短淡入淡出。
局部反转把带尾音的片段反过来，渐强会指向原本的起音。将这个终点对在段落落点。
伸缩与移调分别调整长度或音高。渐变效果只在局部出现时，段落交界更易辨认。
叠加与加工把尾音很短的钢琴与贝斯同奏，可强化贝斯起音。铃声切片也可以只给一句的末尾加镶边调制，保留主体音色的辨识度。

效果音还可以只截取起音，按不同音高映射到采样器的键盘上，组成新的节奏型。合成器贝斯的短音也可以移进高音区，经左右交替的延迟形成有颗粒感的音序器声部。保留有用的预设和切片，便于在合适的段落里比较原声与加工版。
