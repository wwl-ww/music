第一篇 抒情 Ballade

三拍抒情歌《窗沿初晴》用低处的五声短句起笔，逐渐让旋律变密、抬高，直到副歌第一次到达全曲最高音。第二轮副歌后插入一段内省的桥段，最后回到同一个副歌。谱例里保留同一组原创旋律，逐步展示曲式、配词、段落衔接与和弦修订。

晨光意象与段落布局

这首歌的画面从寒气未退的窗沿，移到对晴天的期待，再推开窗户看见整条街被照亮。A 段负责交代环境，B 段使期待逐渐具体，C 段副歌才铺开景色。第二轮照原顺序重现，把改变留给 D 段。D 转入对时间流逝的感受，随后同一个副歌再次出现，因前面有了这一层对照，听感会改变。

A、B、C、D 段的旋律与和声

A 段 · 小调五声旋律与小三度转调

A 从 A 小调的 Am–G 往返开始。前四小节只用 A、C、D、E、G，句子可以在小三度跳进和相邻音之间回转。后半的 Fm–Gm–A♭–B♭ 使和声偏向 C 小调。F 与 A♭ 进入旋律以前，先保留一个 C。C 既可在前半支撑 Am，也是 Fm 的五音，因此伴奏换了调区，旋律还有一处连续的着力点。

小调五声旋律给和声留下余地。A 自然小调的 F 与 A 多利亚的 F♯ 都在这组五音之外。只改伴奏，把 G 换成含 F♯ 的 D/E，前四小节旋律仍可照唱，和声就有了多利亚色彩。判断时要看出现 F♯ 的位置是否与旋律里的 F 同时发声。

B 段 · 关系大调与同主音小调

A 小调转到关系大调 C 大调，两调原有的自然音相同。C–Am 的低音换了，但上方仍能保留 C 和 E。B 把 A 段较稀疏的起音换成连续八分音符，同一速度下听起来更活跃。较长的 B 段可以把 C–Am 再重复一轮，并在 Fm 后展开 Gm、A♭、E♭ 的小调材料，最后用 Dm–G7 拉回 C 大调。Fm 可作为 C 大调借用的 iv，也可以引出一段同主音小调，究竟起什么作用取决于它后面还出现了哪些和声。

C 段 · 副歌音区与两次回收

副歌一开始便向上越过 B 段的音区，最高音 D5 落在两次打开画面的句头，第二次重现因此有明确的记忆点。两句末尾都要回到 C，第一处用 Dm–G7–C（ii–V7–I）立住调性，第二处以 Dm/G 替掉 G7。Dm/G 的低音是 G，上层 D、F、A 分别是它的五度、小七度和九度。省掉 G7 的三音 B，会少一处 B–C 的半音牵引，仍保留 G 到 C 的低音方向。

D 段 · 四度进行与延后的解决

D 从 Fm–B♭7–E♭–A♭ 起步，根音每次上行纯四度或等价地下行纯五度。开头的 Fm 延续 C 小调色彩，B♭7–E♭ 在局部形成属到主的关系。接着 Dm–G7 让人准备听到 C，实际转到 Am，形成 C 大调的阻碍进行。第二乐句用 Fm–B♭7–Gm–Cm，在 E♭ 大调中可听作 ii–V7–iii–vi。D 最后停在 C 大调的 ii–V，直到最终副歌继续展开，桥段自己的末尾先保持开放。

四个主题的旋律与和声草稿

歌词音节与旋律起音

主歌第二次出现时，歌词的新信息应落在原来的句内重心附近。第一段以「檐下风还凉」开头，第二段换成「玻璃上还留霜」。两段都让最后一个字落在第二小节同一位置，并占两拍。第二段把该小节开头的一拍拆作两个八分音符，前一个沿用原音高，后一个同音再起，留出「还留」的两个音节。

同一句尾的两种配词

如果字数差异出现在多个位置，可以在各自的语组内调整。先保住重要词所在的拍位、句尾和换气处，再处理同音重起、分割音值或一字配数音；否则字数虽然对得上，听众可能仍会听错分词。

前奏、间奏与尾奏的材料

前奏进入 A 小调时，先用 Am–F–Dm 让根音连续下行三度。F 与 Dm 共用 F、A，若上声部依次下降，共同音仍能稳住连接。经过 Em 后，后四小节沿用 A 的 Am–G 往返，下行的引子就过渡到了主歌的和声循环。

间奏从刚结束的副歌借来 F–G–Am，即 C 大调的 IV–V–vi。重复这组材料后，用 Dm 接 E7，把 G♯ 引向下一段 Am 的 A。尾奏保留相同的第一句，后面改为 Dm–G–C，再把 C 与 Csus4 交替。两段同从副歌出发，间奏的属七要等下一段才解决，尾奏的解决已经在本段里发生。

前奏、间奏与尾奏的去向

挂留终止与变格终止
  • Csus4–C 保持 C 低音，用四度音 F 暂时代替三度音 E，尾声形成一个四度向三度的解决。
  • 传统的变格终止通常是 IV–I，C 大调里是 F–C。「阿门」式收尾带来的相似感来自 F 回落到 E，Csus4–C 的低音始终留在主音。

和弦修订与旋律兼容性

等旋律轮廓和段落去向都能成立，再选出需要变色或导向的拍点。在同一段试听中保留旋律和速度，比较换和弦后发生变化的低音、共同音与解决音。

同一段落的原型与修订和声

替代和弦的共同音依据
  • E7 的 G♯–D 与 B♭7 的 A♭–D 是等音相同的三全音，因此可替换属低音而保留部分趋向。B♭9 中的 C 也可以留作 Am9 的三音。
  • F/G 与 Dm/G 都可出现在 G7 的位置，也都保留低音 G 和七音 F。F/G 的 C 与 A 分别提供十一音和九音，Dm/G 则用 D 代 C。省去属三音 B 后，走向主和弦的力量更多由低音 G–C 和 F–E 提供。
  • D♭maj9 的 D♭、F、A♭、C、E♭ 也是 B♭m7(9,11) 省去根音后的一组音。这里要检查的是旋律 F 与回来时的 Am9，省根音提供一种解释，并不要求在现场听到 B♭。
  • 旋律若在 F 上停留，把下方的 F 换成含 F♯ 的和弦会让两音相距半音，宜另选衬托。G7(♭9) 的降九音拼写为 A♭，它和弦根音 G 的抵触在进入 C 后解除。

完整示范《窗沿初晴》

伴奏以低音落在第一拍、较轻的和弦落在第二和第三拍建立三拍脉动。既可以用钢琴奏出，也能把第一拍的分量分配给低音或轻打击乐。需要延长句尾时，上层和弦可以减为一次起音，拍点仍由低音位置维持。合成器的长音能补足钢琴的衰减，少量钟铃音可以点出句头或段落变化。示范用钢琴呈现和声与节奏，主旋律保持清楚，再以渐慢的挂留解决结束。
