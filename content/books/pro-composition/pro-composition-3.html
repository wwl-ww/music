主题配色

第三篇 色彩鲜明的 POP

《窗外有风》写一个人从反复思量走到重新出发。主歌在短音与循环和声里打转，副歌提早出现，把明亮的轮廓立起来。真正低沉的桥段留到第二轮之后。此时再唱同一个副歌，「重新出发」才有分量。

情绪走向与段落布局

全曲以 E♭ 大调为主。开端的不安可以来自反复的短句和没有走远的和声。到 B，局部的调性开始移动，听到一点出口。C 副歌用提早出现的高音、同音反复与清楚的和声目标打开音响。D 只出现一次，把前面一直压住的低谷写出来，留给最后一轮副歌一个鲜明的对面。

《窗外有风》的段落顺序
段落写作任务
前奏Ⅰ → 前奏Ⅱ先用四小节节奏抓住注意力，再加入旋律与和声。
A1 → B1 → C1 → 间奏Ⅰ交代处境，逐渐松动，再进入副歌。间奏把副歌送回 A。
A2 → B2 → C2 → 间奏Ⅱ重现主题材料，歌词继续推进。间奏保留和声，改换音色与起音位置。
D → C3 → 尾奏桥段回望低谷，第三次副歌恢复前面的明朗，尾奏完成收束。

主题旋律与和声骨架

A 段 · 短句循环与两种句尾

前四小节的 E♭–Fm7–Gm7–Fm7 相当于 I–ii7–iii7–ii7。旋律在近处来回走，后半又从同一个节奏起头。第 4 小节后半用 A♭/B♭ 代替直接返回主和弦前常用的 B♭7。B♭ 低音仍把耳朵引向 E♭，上方 A♭ 大三和弦却保留了属七和弦的七音 A♭，同时带来九音 C、十一音 E♭，省掉作为属和弦三音的 D。这个挂留式音响让第一次回到 I 稍缓一点。

第 8 小节需要送去 B 段开头的 A♭，句尾改为 B♭m7–E♭7。把目标 A♭ 暂视为 I，这对和弦就是它的 ii7–V7。前半句回到 E♭，后半句托起下一段，旋律就能反复而不在原地结束。

B 段 · 从关系小调转向 G♭ 大调

A♭–G7–Cm–F7 让 c 小调短暂浮现。A♭ 在原来的 E♭ 大调是 IV，也是 c 小调的 VI，G7 中的 B♮ 把方向明确指向 C。接着 A♭m–D♭7–G♭ 建立 G♭ 大调的 ii–V7–I。以原来的大调主音 E♭ 为参照，新主音 G♭ 高小三度。旋律在新调略抬高，焦虑开始有了出口。

最后一小节再用 Fm–B♭，给出 E♭ 大调的 ii–V 线索。副歌却从 A♭（IV）开始，要等后续的 Fm–B♭–E♭ 才真正落到主和弦。段落交接可以先让新调变得可预期，把明确的归主留给下一段。

C 段 · 共同和弦与两次回归

副歌的主体有十二小节。前两小节的 A♭–B♭–Gm–Cm 属于 E♭ 大调的 IV–V–iii–vi，末尾的 Cm 也可作为 c 小调的 i。接着写 Fm–G7–Cm，按 i–iv–V7–i 稳住这一小段小调。把同一个 Cm 换一种功能理解，调性的明暗就能在同一副歌里交替。

十二小节可听成三个四小节单位。第 5、6 小节重现题头，随后以 Fm–B♭–E♭ 回到大调。第 9、10 小节再次用同一条 ii–V–I 弧线，末两小节却留下 Fm、B♭，最后一个字落在下一段的入口。和声与音色可以在新段开始，旋律仍在完成上一句，所以曲式上的十二小节与一句唱词占用的小节不必完全重合。

D 段 · 同主音小调与下行全音转调

桥段放在最后一轮副歌前，只出现一次。E♭ 大调换成 e♭ 小调，主音保持 E♭，旋律的三音降为 G♭，和声在 E♭m、D♭ 间往返。第 5、6 小节用 F♯m–C♯m，形成 c♯ 小调的 iv–i。C♯ 与 D♭ 等音，主音比 E♭ 低一个全音。最后两小节用 E♭ 大调的 Fm–B♭7，重新建立返向副歌的方向。

四段主题与和声走向

同一个二五连接随目标改变。 B♭m7–E♭7 指向 A♭，Fm–B♭ 指向 E♭ 的调性。实际落在哪个和弦，还要看下一句从哪里开始。

副歌换词与音符拆分

A、B 的两轮歌词可以在相同旋律上叙述不同细节。三个副歌里，C1 与 C3 用相同的词曲形成首尾呼应，C2 的两句话各多出一个字。这里保留音高和换气位置，把原来一个四分音符拆成两个同音高的八分音符，音符总长和句末重心都维持原样。

同一副歌轮廓的两种字数

如果再多出几个字，继续切成更短的音符容易挤掉语气和换气。这里多出的字都放进能够分割的位置。假如位置落在需要保留的长音或句尾，调整歌词措辞也能解决字数差。

前奏、间奏与尾奏

前奏 · 先建立节奏，再展开副歌和声

前奏Ⅰ只有四小节节奏。前奏Ⅱ加入旋律与和声，副歌头两小节里的 A♭–B♭–Gm–Cm 从每两拍换一次延长为每小节一次，让前奏有自己的速度感。后四小节用 Fm–Gm–A♭ 的 ii–iii–IV 上行制造期待，末小节的 Fm–B♭7 与 A 段首和弦 E♭ 合成 ii–V7–I。

两次间奏 · 共同音承接与换和弦加速

副歌的最后一个音 E♭ 继续发声，间奏首和弦用含有 E♭ 的 A♭。接下来 A♭–Gm–Fm–E♭–D♭–Cm 让根音逐级往下走。最后两小节改成两拍换一和弦，Fm–Gm–A♭m–B♭m 让根音往上走。A♭m 与 B♭m 借自同主音的 e♭ 小调，增加了通往下一段的色彩。两次间奏保留和声路线，第一次用马林巴呼应前奏，第二次用起音较迟的吉他旋律引向桥段。

尾奏 · 主和弦与下属和弦的反复

初稿用 E♭–A♭ 往返，让最后一次副歌留下的明亮气氛多停留片刻。相同的两和弦可按所需时长反复。本例用九小节，末小节停在 E♭。

段落连接的五种写法

和声修订与改动位置

旋律定下来后，和声仍有三种可以分开处理的变化。可以保留上方音改低音，可以给原和弦补七音或九音，也可以在原来只放一个和弦的小节里，分几拍安放下一句需要的连接。副歌和桥段的对照保留同一条旋律，便于定位听到的变化。

前奏第 6 小节仍指向 c 小调的色彩。c 小调属七 G7 里的 B♮ 与 F，在 D♭9 里仍可听到等音的 C♭ 和 F，因此 D♭9 可作为 G7 的三全音替代。这里没有让它解决到 Cm，而是接 Dm9，出现 C 大调 ii9 的色彩。这种很短的调性暗示可以丰富接缝。尾奏则把 Cmaj9 留在最后，让 C 成为明确的归宿。

桥段同时给 E♭m、F♯m 加七音，为 C♯m 增补七音、九音与十一音。这些音让重复的小调保持辨识度，又给每个落点不同的厚度。第 8 小节插入根音高小三度的 D♭9，F 从 D♭9 的三音变为 B♭7 的五音，旋律可保持不动。真正为 E♭ 大调准备属功能的仍是后半小节的 B♭7。

草稿与修订的和声对照

完成曲 ·《窗外有风》

弦乐副旋律在主旋律的长音与留白里接出回应。主唱字密时，副旋律多用长时值，避免形成两个同时争夺重音的短句。歌声走到句尾，弦乐可以再往前带一步。间奏与尾奏首小节仍有副歌的最后一个字，段落边界由和声与音色提示。
