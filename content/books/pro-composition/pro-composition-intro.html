导论 从构思到成曲

有了一句能哼出来的旋律，接下来要决定它在整首歌里做什么。每个案例都从一个情境出发，给各段安排任务，再写旋律与和声、配歌词、补前奏和段间连接，最后修订和声并把各段连起来。

情境与段落分工

同一个短句放在开头，可以交代人物和处境。放在副歌，可以变成听者反复记住的一句话。段落功能明确以后，才能判断哪里值得重复、哪里需要改变。以一首写「夜里迷路，最后看见灯」的歌为例，A 段交代困境，B 段增加寻找的动作，C 段让灯出现。A 可以用窄音域和短节奏，B 改变句尾或和弦去向，C 再把音区和时值拉开。速度、音区与节奏疏密分别影响听感，同一种情绪也可以有多种速度。

字母代表可辨认的一组主题材料。A₂ 若保留 A₁ 的主要旋律而换歌词，仍是 A。D 可以用新的旋律与和声形成对比。这个编号说明材料的关系，主歌、副歌、过门则说明它在歌曲里承担的任务。

主题旋律与和声草稿

可以同时写旋律与和弦，也可以先定和弦骨架，再给各段写旋律。后者适合处理只有一个动机的草稿。先决定句尾落在哪个和弦，接着在句头、重拍或长音处挑选和弦音，短音再负责连接。

调内和弦与功能

以音阶每一级为根音，按三度叠到五音就是三和弦，继续叠到七音就是七和弦。级数表示根音与主音的关系，和弦符号表示音程结构。例如 Dm7 是 C 大调的 ii7，音为 D、F、A、C。在 A 自然小调里，同一个 Dm7 起于第四级。判断主、下属、属功能时，还要结合前后走向。

大调和三种小调的调内七和弦

大调写作常以 I、IV、V 为支点。I 确立调性，IV 提供离开主位后的展开，V7 中三音与七音之间的三全音形成回主倾向。同一调里每个和弦有自己的根音，但都以同一主音为参照。例如在 C 大调中，Dm7 的根音是 D，整段的主音仍是 C。

大调与自然小调的常用功能位置
功能C 大调示例A 自然小调示例
主功能C 是归宿，Am、Em 可延续或改写主功能。Am 是归宿，C 可延续相近的音响，也能引向关系大调。
下属与属前F 或 Dm 都可为 G7 作准备。Dm 或 Bm7(♭5) 都可接属和弦。F–Dm、G–Am 也可拓展自然小调的句子。
属功能G7 的 B–F 指向 C–E，Bdim 也含 B–F。Em7 可以回到 Am。若需更明确的导向，用 E7 让 G♯ 上行到 A、D 下行到 C。

功能表示和弦在句子中做的事。C 与 Am 共享 C、E，所以有时能互换。若把明确的 G7–C 改成 G7–Am，句尾会变成阻碍进行。共同音可以维持旋律，低音和落点仍会改变句法。

和弦符号的读法
  • Cmaj7 与 C7的下方都是 C、E、G。Cmaj7 的七音是 B，C7 的七音是 B♭。单写 7 时指小七度，maj7 才是大七度。
  • Amadd9 与 Am9都加入 B。Amadd9 只把 B 加在 A、C、E 上。Am9 还包含小七音 G。
  • Csus4 与 C/E改变的位置不同。Csus4 在 C、G 之间用 F 替换 E。C/E 仍有 C、E、G，只指定 E 做最低音。
  • Bm7(♭5) 与 Bdim7都含 B、D、F。前者的七音是 A，后者是 A♭。和弦级数里的 iiø7 也是半减七和弦。
大调与小调的常用和弦进行
  • C 大调循环可从 C–Am–Dm–G 或 C–Am–F–G 起步。也可从 Dm–G–C–Am 开始，或采用 F–G–Em–Am 形成小调落点。
  • F–Em–Dm–C 的根音级进下行。C–F–G–C 的功能路径清晰，C–G–C–G 反复强调主属。C–G–Am–Em–F–C–F–G 是常用的卡农型进行。Dm–G–C–F 延续根音上行四度的推动。
  • A 自然小调的 Am–G–F–Em 下行，Am–C–Dm–F 则往上展开。Am–C–D–G 中 D 大三和弦的 F♯ 改变了自然小调的色彩。
  • Am–F–Dm–E7、Am–C–F–E7 都以 E7 预备下一轮 Am。Dm–Bm7(♭5)–E7–Am 的最后三项构成小调的 iiø7–V7–i。

和弦音、扩展音与经过音

扩展音是可作为和弦色彩保留的九音、十一音、十三音等。相同的调内音换到另一和弦上，其角色也会变。F 在 Dm 里是三音，在含 E 的 C 或 Am 和弦上长停，则容易与 E 形成半音或小九度摩擦。规避音指特定配和弦中通常避免作稳定长音的音。若需要这股张力，可以给它解决方向。这里的 F 可在弱位经过，也可先停留再下行到 E。调外音同样能连接稳定音。先现音则提前奏出下个和弦的音。

和弦音骨架与装饰后的旋律

当同一套调内和弦不足以表现段落变化时，可以换调。关系大小调（如 C 大调与 A 小调）有共同音列，同主音大小调（如 C 大调与 C 小调）保留主音但改变多个音级。小三度换调和更远的换调可以借共同旋律音或新调的属和弦衔接。一个借用和弦可以保留原主音，形成新主音感才构成转调。

歌词字数与起音

同一旋律反复时，两段歌词未必字数相等。可以把一个长音拆成两个短起音，或将两音合成一个较长的起音。改写尽量留在弱位，把关键信息与句末所在的拍点保住。一个字唱几个音时，可以用连线标示同一音节的延展。

前奏、间奏与尾奏

前奏给听者一个可辨认的声音预告。用副歌和弦写前奏时，可以保留次序，改变换和弦的速度，或抽取前四个和弦，让副歌首次进入时还有新内容。另写材料也可以，交接处要留出下一段能接住的音或节拍。

间奏连接两段，末尾的和弦可以服从下一段的入口。若下一段从 Am 起，间奏尾用 E7，G♯ 到 A 和 D 到 C 都能把听者带过去。尾奏负责决定音乐怎么停，既可以借回前奏形成首尾照应，也可以延长最后一个主和弦。前奏的最后一个和弦若原本用来向前推，原样拿来收尾就可能仍有悬念。

例如一段要回主歌的过门和一段要结束全曲的尾奏，都可以从 Dm 开始。前者接 E7 后把 Am 留给主歌开头。后者接 G7–C，并把主和弦留在尾奏里。同一开头之所以能服务两处，是因为结尾的目标不同。

和声修订与成曲

骨架能撑住旋律后，和声修订才有比较的基准。改变低音时，观察它能否连成一条线。加扩展音时，观察最上方的音能否与旋律和前后和弦相接。替换和弦时，确认旋律的长音与新和声仍能共存。

和声骨架及常用修订

扩展音、斜线低音与临时属功能
  • 九音、十一音和十三音从根音向上计算。G7 上的变化扩展音可以有 ♭9、♯9、♯11、♭13，具体取舍取决于其解决方向与旋律音。Fmaj7 上的 B 是 ♯11，来自 C 大调本身，也能成为平滑的上声部。
  • 以 C 大调的调内九音为例，Cmaj7 加 D，Dm7 加 E，G7 加 A，Am7 加 B。比较十一音时，Fmaj7 上可用 B，Dm7 上可用 G。不同结构的和弦适合保留的扩展音并不完全相同。
  • 斜线后写实际低音，F/C 的 C 是和弦音，C/D 的 D 在上方三和弦之外。持续低音指在连续几个和弦下保持同一低音，一枚斜线和弦自身无法形成持续过程。
  • C 大调的 Dm、Em、F、G、Am 可分别由 A7、B7、C7、D7、E7 临时导入。若目标是 G，Am7–D7–G 又构成以 G 为局部主音的二–五–一。
  • C♯dim7–Dm7 中，导向 D 的半音低音提供连接。全减七还可以重新拼写来指向别的目标。区分三全音替代时，两和弦都应有可互换的属功能。

每次修订要能说明改变了哪一层。 把旋律和段落先保留，比较低音、换和弦的拍位或上方音，才能判断变化是否帮到了作品。
