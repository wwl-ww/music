第二篇 巴萨诺瓦

这次保持共同旋律的音高与时值，让前半段的和声少换几次。在 C 与 F 的低音上共用三条上声部，之后把一条半音下行线藏进小和弦。明确的二–五进行留到句尾。

巴萨诺瓦成品与调式思路

巴萨诺瓦在 20 世纪中叶的巴西发展，编和声时常借用爵士的声部安排。沿用爵士篇的办法，连续加入副属和弦，会让每个小节都显得在等待局部解决。这里优先照顾共同音阶中的旋律，让和弦较长地延续、降低和弦转换的频率。尼龙弦吉他或电钢琴都能承担切分音型，低音持续交代每小节两大拍。

调式思路先处理主音和音阶特征，再安排旋律与配和声的关系。这里采用 C 伊奥尼亚，即以 C 为中心的自然大调音阶。C 低音之上的配和声可以省略 E，用以纯四度为骨架的上层放宽三和弦对旋律的约束。它仍保有 C 的音阶背景，清楚的二–五–一收束安排在后面。四度配置是可选手法，和声密度、节奏与音色也参与风格塑造。

十六小节旋律的巴萨诺瓦重配

十六小节旋律之下，尼龙弦吉他在正拍与反拍入拍，低音维持两大拍。尾奏附加四小节，回用 C 与 F 上方的共同四度排列。

减少前段换弦，保留句尾的属功能

先用三和弦试配。共同旋律第 1、2 小节的长音 C 都可留在主和弦上。第 3 小节最后的 F 若也配 C，会与和弦的 E 相距半音。保留 F 后，这个音成为和弦根音，之前的 A 也成了三音。决定哪里延续主和弦时，旋律在强拍或句尾的停留音比单纯减少换弦更重要。

在中段减轻回主前的属压力。基谱第 8–10 小节是 G–G–C，低音维持两小节的属音后回主。改配在这一带让 F6、Fm6 延续下属区，把较明确的属七回主留到曲末。旋律里的 D 是 F6 的六音。第 9 小节开头的 B4 在 Fm6 上仍较鲜明，配谱中把与它相邻的音级 C 放到 C4，拉开到大七度。若还希望减轻这个色彩，可把 Fm6 延后到旋律进入 D5 的第二拍。

安排中段的替代时，只把一个主功能区域改成 Am。Am7 和 C 共用 C、E、G，能维持原调上下文。根音 A 还能成为半音下行的起点。先保留句尾的 Em7–Am7–Dm7–G7–C，确立低音 E–A–D–G–C，再决定是否在第二个位置把 Am7 改作副属 A7。先做这层安排，后面调声位时便知道哪些落点要保住。

固定上方音组的四度配置

从根音直接往上连叠纯四度，C 上会得到 F、B♭、E♭，其中 B♭ 与 E♭ 已脱离 C 大调。可先把 C 留作低音，再从 C 大调音阶挑出能连续叠纯四度的上方音组。A–D–G 有两组纯四度，不包含主和弦的三音或七音。C 低音帮助维持主音，旋律出现 E 时再把大三度补出来。

在固定低音上从不同音起叠

以主音 C3 保持最低，先选上方三音的起点，再连续上行两个纯四度。例如从 E3 开始，接 A3，再接 D4。从 A3 开始则接 D4、G4。比较时，把低音和旋律固定，查看候选是否增加调外音、是否把主音再加重、以及最上面的和声音是否挤近旋律。

固定 C 低音的四度叠置候选

上方 A3–D4–G4 是连续纯四度。旋律 E5 补出大三度，伴奏顶音低于旋律。

上方三音保持，低音从 C 换到 F

同一组 A–D–G 可以移到 F 低音上。A 随之成为 F 的大三度，D、G 则可作为六音和九音。旋律第 3 小节的 A、G、F 与它们相互补充。伴奏仍在同一个音区，只改最低音就能区分 I 与 IV。若连续换声部的方向，反而会削弱这种平稳感。

这份谱面以 C、F 标识低音和功能。实际和声音由谱上音符决定。C 低音上没有三音 E，也没有四音 F，因此不能按 C 大三和弦或 Csus4 弹奏。若只写给演奏者看，可以直接把所需上方音组写在谱上，保留它的四度排列。

保留单个四度与连续低音

先决定低音。第 10–13 小节的 C/E 与 F 已能让 E–F 作半音交替。再分别给 C 加 D、给 F 加 G，两个和弦都能获得九音，却不必共用同一组上方音。若在 C 上用 A–D–G，较高的 A 可能与旋律 G 相隔全音。若在 F 上完全照搬 C 的上方排列，F 的三音 A 可能消失。两处都要检查各自的功能是否还够清楚。

若把 Cadd9/E 的 C 放到 C5、Fadd9 的 A 放到 A4，和声顶音随低音交替。C5 会同旋律 C5 重合，A4 也靠近旋律 G4。把顶音统一到 G4 后，Cadd9/E 留 D4–G4 的四度，Fadd9 留 C4–F4 的四度，F 的三音 A 仍保留。这样可以留下局部的四度音响，让和声顶音保持稳定。若歌手仍难以辨认自己的音，最初只有 C/E 与 F 的版本也成立。

半音低音与固定顶音的三种排列

C/E 与 F 交替。低音已经作半音移动，和声保留三和弦。

和弦内半音线与下属小和弦

和弦内的单条线可用半音或全音移动，让同一个和弦区域逐渐展开。这种手法称为和弦线条（line cliché）。这里在第 5 小节进入 Am，尽量保留上方 C、E，让低音 A–G♯–G–F♯，再走到 F。第二个位置的 G♯ 是 A 的大七音，离 A 最近，可省略重复的 A。接着的 G 是小七音，F♯ 是大六音。相同的线也可放在伴奏内声或顶端。

这一写法从一条半音线开始，再给每个位置命名。若保持 A2，移动上方的 A4，就会依次听见 Am、Am(maj7)、Am7、Am6。若把同样的线交给低音，和弦加斜线标出最低音，C4 与 E4 可始终保留。内声版本的做法也一样，只需让那条线留在外声部之间。

F6 保留低音 F，加入六音 D，可容纳旋律的 D。到 Fm6 时，把 A 改成 A♭，C 与 D 留在原处。低音不动，调式借用的色彩集中在一个声部，常用来表现略带感伤的情绪。旋律缺少相邻的 A 长音时，这个 A–A♭ 容易被听为和声变化。半音线和下属小和弦的作用可分别比较。

持续根音、半音低音与下属小和弦

从 Am 经过句中走向 F6。前两小节低音都停在 A。

连续二–五与四度尾奏

Dm7–G7 已经建立 C 大调的二–五关系。再用 A7 指向 Dm7，让前面的 Em7 成为 A7 的相关 ii7。两组二–五就能连为一句。较早的和声顶音已固定为 G，末句也可保留 G。Em7 的 G 是三音，A7 的 G 是七音，Dm7 的 G 是十一音，G7 的 G 是根音。同一个音换了身份，声部依然连贯。

固定 G 后，逐次检查它下面的两个位置。把 Em7 中的 D 下移半音，正好得到 A7 的三音 C♯。继续到 Dm11 的 C、G7 的 B，形成 D–C♯–C–B。另一条内声由 Em7 的 B 出发。A7 的降九音 B♭ 和 G7 的降九音 A♭ 分别接在 B、A 后面，得到 B–B♭–A–A♭。

每个位置只留四个伴奏音，让低音、两条半音线与顶音都有自己的位置。Dm11 可省略三音 F，G7(♭9) 可省略五音 D 和七音 F。成品第 15 小节末的旋律会补回 F。以下近距离排列使用另外一条短旋律，方便看清两条内声。成品第 14 小节后半的旋律为 D5，所以把 A7 的 C♯ 移低八度。

两组二–五、固定顶音与半音低音

Em7–Am7 之后仍有 Dm7–G7。G7–C 明确承担最后的回主。

结束后回用开头 C、F 的四度上层，再以 F–C–F–C 做四小节尾奏。低音确认 C 的落点，上方 A–D–G 延续前段较开放的音响。若让吉他承担这组和声，可分配到不同弦组、移动八度或省去重复音，低音交给独立声部。
